## 三、使用建议

- 工具选择：Gamma（生成质量高）、WPS AI（国内可达）、Kimi PPT（免费、中文好）
- 若生成器要求「每页只留一个指令」，把上面各页 `【第 N 页】` 拆开逐页投喂
- 深色科技风关键词建议：`dark tech / lake blue gradient / glassmorphism / data screen / dashboard`
- 需要配套封面背景图时，可再补一句「封面用太湖遥感影像或等高线网格做底图」
