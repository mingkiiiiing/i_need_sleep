> 对应赛题：A23 · 基于机理和AI融合的地表水蓝藻水华监测预警模型设计与实现

## 一、GitHub 上最值得参考的项目（按与本赛题相关度排序）

### 🥇 与赛题技术栈/场景最匹配

| 项目 | 说明 | 参考价值 |
|---|---|---|
| [dragonxu/WQMFS（水质管理与预测系统）](https://github.com/dragonxu/WQMFS) | **国内开源**，Vue + SpringBoot + Django/Keras，内置 LSTM/SVR/RVR/Adaboost/BP 五种模型择优预测，数据就是**太湖流域 672 条水质记录**（溶解氧、pH、氨氮） | ⭐️ 与赛题几乎同场景，可参考其模型训练、对比、管理模块的设计 |
| [LeiGao2016/cyanobacterial-concentration-prediction-HybridModel](https://github.com/LeiGao2016/cyanobacterial-concentration-prediction-HybridModel) | **DWT + LSTM + ARIMA + 残差补偿模型**（论文官方代码，墨累河流域，RMSE 低至 647 cells/ml） | ⭐️ 与赛题「机理+AI 残差学习融合」思路**直接对应**，`ai_models.py` / `fusion.py` 可借鉴 |
| [pommevilla/one_week_ahead](https://github.com/pommevilla/one_week_ahead) | 爱荷华州 39 湖泊**提前一周**有害藻华预测，XGBoost + 逻辑回归集成（ROC AUC 0.956），完整 Snakemake 管线 | 多源数据融合（水质+气象+土地利用）的做法可参考 |
| [HabLSTM](https://www.scilit.com/publications/51e867b49ad03a9fe009baa4a6350de4) | **基于太湖实测数据**的非平稳聚焦 LSTM 时空预测（Taihu HAB A/B 数据集，Himawari-8 卫星 NDVI） | 赛题场景 1:1，答辩引用好素材 |

## 三、其他国外开源/学术参考

- **Lake Lugano 开源预警原型**（[ISPRS 论文](https://isprs-archives.copernicus.org/articles/XLVIII-4-W12-2024/143/2024/)）：Raspberry Pi IoT 荧光计 + NB-IoT + istSOS 的完整低成本预警系统
- **FLARE-forecast**（[FLARErLER](https://github.com/FLARE-forecast/FLARErLER)）：湖库生态**近实时滚动预报 + 数据同化**框架
- **PredRNN 蓝藻水华时空动态预测方案**（[CSDN 文库](https://wenku.csdn.net/doc/5wytb2m4u2)）：MODIS 遥感 + 浮标水质 + ERA5 气象多源融合，未来 3-7 天**像素级**水华空间分布预测，预警提前量 ≥ 48h——时空双预测思路可写进方案书
- **学术论文**（无公开代码，但方法可直接复现写进报告）：
  - [RF-LSTM 滇池蓝藻水华预测](https://www.rjdk.org.cn/zh/article/doi/10.11907/rjdk.231864/)（MODIS NDVI 指标，预测精度 90.9%，优于单一 LSTM/RF）
  - [GF-LSTM 太湖梅梁湖水华预测](http://www.joca.cn/CN/Y2018/V38/I7/2119)（遗传算法改进滤波 + LSTM，被引 26 次，平均相对误差 16%~18%）
  - [Attention-BiLSTM 太湖水华预测](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002877934)（河海大学，CNN 特征提取 + BiLSTM + 注意力机制）
  - [1D CNN-SLSTM 太湖蓝藻密度预测](https://wenku.csdn.net/doc/5wytb2m4u2)（一维卷积 + LSTM + SELU 激活，优于单独 LSTM）
  - [多变量 LSTM 早期预警（Water Research 2024）](https://www.x-mol.com/paper/1841930268079742976/t)：6 年高频数据，4-28 天时域预测，10μg PC/L 警报准确率 90%，可提前 16-28 天预警
  - [随机森林 + SHAP 可解释预警框架](https://news.ebiotrade.com/2026-5/20260507000824512.htm)（同济大学 2026）：SHAP 揭示温度/光照关键阈值，AUC > 0.95——与赛题「可解释性」要求直接对应

## 四、落地建议（针对本赛题）

1. **机理模型**：不必从零造轮子——GOTM/FABM 或 GLM 就是开源的"藻类生长动力学"标准实现，可摘取其温度/光照 Monod 限制函数公式做简化版（`dB/dt = μmax·f(T)·f(I)·f(N)·f(P)·B − m·B`），并在报告中注明参考来源
2. **AI + 融合**：残差融合直接对标 [HybridModel](https://github.com/LeiGao2016/cyanobacterial-concentration-prediction-HybridModel) 的「残差补偿」架构；太湖数据场景对标 [HabLSTM](https://www.scilit.com/publications/51e867b49ad03a9fe009baa4a6350de4) 与 GF-LSTM
3. **数据叙事**：WQMFS 的太湖实测数据 + PredRNN 的多源融合方案（遥感+浮标+ERA5）可以让种子数据"有来源、有依据"
4. **可解释性**：同济大学 RF+SHAP 框架与赛题"驱动因子贡献度排序（水温/总磷/氨氮/流速/光照）"要求完全一致，是论文级背书
5. **演示参照**：水脉卫士（三维 + 预警全生命周期）与 B站数字孪生智慧水利视频是演示/答辩形态的最佳参照
