## 统一视觉规范

- 画布：16:9 桌面 Web 应用，目标 1920×1080。
- 风格：严肃、可信、可落地的水环境监测产品 UI；不是概念艺术海报。
- 背景：深海军蓝 `#06111F`；玻璃面板保持克制，边框青色低透明度。
- 主色：青色 `#22D3EE`、青绿 `#14B8A6`。
- 风险色：绿/黄/橙/红；同时使用文字或图标，不只依赖颜色。
- 结构：左侧 72px 图标导航，顶部 64px 状态栏，内容区 12 列栅格。
- 字体：现代无衬线中文；只要求主要标题和按钮清晰，避免生成大量不可控小字。
- 禁止：品牌 Logo、水印、浮夸霓虹、不可实现的全息控件、过度装饰、手机外壳、透视倾斜整页。

## 页面提示词摘要

### P01

中央 3D 太湖沙盘占 55%，带水面、8 个站点光柱、红橙绿风险网格和轻量扩散粒子；左右两侧分别为 KPI/站点排行/趋势、站点详情/驱动因素/最新预警；底部为历史—当前—未来时间轴。

### P02

数据治理后台，顶部 5 个质量 KPI；左侧水质/气象/水文/遥感数据源；中央接入任务表和上传按钮；右侧质控漏斗、缺失异常图；底部可编辑问题明细。

### P03

站点研判，左侧站点筛选列表；中央上部 2D 湖图站点，中央下部多指标趋势；右侧站点档案、实时指标、质量、最新预测与预警。

### P04

参数反演工作台，左侧遥感场景缩略图；中央大幅原始影像与叶绿素反演热力卷帘对比；右侧算法和参数；底部实测—反演散点、残差和 R²/RMSE。

### P05

融合预测中心，顶部完整筛选条件；主图同时显示实际、机理、两种 AI、两种融合曲线和 95% 区间；右侧任务/峰值/风险摘要；底部真实指标和融合提升表。

### P06

解释页，左上 SHAP beeswarm，右上 waterfall，左下敏感性曲线，中下不确定性区间与风险概率，右下由证据驱动的中文原因说明。

### P07

时空推演页，中央 2D/3D 风险地图和历史/预测分界；右侧当前帧与网格详情；底部播放时间轴和 A/B 帧对比；强调风险扩张与消退。

### P08

预警处置台，左侧按等级/状态的预警列表；中间事件详情和状态时间线；右侧推荐预案和措施勾选；底部处置/推送/审计日志；突出确认、指派、开始处置、关闭按钮。

### P09

模型实验管理，左侧模型版本树；中央指标比较、散点/残差；右侧模型版本和在线状态；底部训练运行和日志；顶部有“新建训练”“加入对比”“启用”“回滚”。
