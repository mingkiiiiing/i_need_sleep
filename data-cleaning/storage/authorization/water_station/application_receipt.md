## 3. 申请对象与范围

### 3.1 站点和空间范围

- 太湖全湖自动站和浮标；如无法提供全湖，优先梅梁湾、竺山湾、西部沿岸、湖心及主要饮用水源地附近站点。
- 请同时提供站点元数据：站点编号、名称、经度、纬度、采样水深、所属湖区、设备类型和高程/坐标基准。
- 如数据来自入湖河道或出湖口，请注明河道方向、断面和与太湖边界的关系。

### 3.2 时间范围与最低样例

- 首选历史范围：`2019-01-01` 至申请时可提供的最新日期，至少覆盖 3 个完整年度和 3 个蓝藻暴发季。
- 准实时增量：最近 30 天至最新可提供时间。
- 最小验收样例：连续 7 天、无删减原始记录，包含完整时间戳和质量码。
- 若只能提供短样例，请说明可提供的完整藻季范围、历史数据起止时间和更新延迟。

### 3.3 频率与格式

- 优先频率：15—30 分钟或小时级；水质营养盐若无法高频提供，可接受日/周级。
- 优先格式：CSV/XLSX/JSON；如使用 HJ 1404 流式报文，请提供字段字典和报文示例。
- 时间要求：注明时区、夏令时处理、发布时间与观测时间；不得将本地时间无标识地转换为 UTC。
- 原始值、质控值和缺测码均保留，清洗结果另行存放。

## 4. 最小字段清单

### 4.1 必需字段（P0）

| 字段 | 单位/编码 | 说明 |
|---|---|---|
| `station_id` | 字符串 | 站点或浮标唯一编号 |
| `longitude`、`latitude` | degree，WGS84或注明坐标系 | 空间对齐与水体掩膜 |
| `observed_at` | ISO 8601，含时区 | 观测时间；另附发布时间和时间频率 |
| `water_temperature` | °C | 藻类生长温度限制函数 |
| `chlorophyll_a` | µg/L | 叶绿素 a 地面校准真值 |
| `algae_density` | cells/L 或 cells/mL | 藻密度，必须注明计数方法 |
| `cyanobacteria_phycocyanin` | µg/L 或仪器单位 | 蓝藻荧光/藻蓝蛋白，注明仪器和校准 |
| `dissolved_oxygen` | mg/L | DO，水质与生态状态 |
| `pH` | dimensionless | 水质状态 |
| `turbidity` | NTU 或 FNU | 浊度，注明仪器量程 |
| `total_phosphorus` | mg/L | 总磷限制因子 |
| `total_nitrogen` | mg/L | 总氮限制因子 |
| `ammonia_nitrogen` | mg/L | 氨氮营养盐因子 |
| `quality_code` | 供应方编码 | 通过、缺测、异常、校准、维护等状态 |

### 4.2 建议字段（P1）

- 水深、透明度/Secchi 深度、电导率、流速/流向、氧化还原电位；
- 硝态氮、亚硝态氮、正磷酸盐、CODMn、悬浮物；
- 仪器型号、校准时间、维护/停机事件、检出限、异常原因和单位字典；
- 采样方式（在线传感器、人工采样、实验室分析）及实验方法。

## 5. 数据用途与授权承诺

数据仅用于大学生科研与 A23 竞赛，不用于商业经营。用途包括：

1. 多源水质、遥感和气象数据的清洗、异常检测、缺失值插补和时空对齐；
2. 叶绿素 a、藻密度和藻蓝蛋白遥感反演的地面校准；
3. 机理模型参数率定、AI 预测训练、1—3 天短临状态验证和风险分级评估；
4. 数据质量报告、模型验证报告和竞赛演示，不制作未经许可的原始数据公开包。

申请人承诺遵守提供单位的使用、署名和再分发条款；未经书面许可不转发原始水站/浮标文件；衍生统计结果和模型参数按授权范围处理；在成果中标注提供单位、数据版本、时间范围和访问日期。
