## 3. 申请范围

### 3.1 空间范围

- 太湖湖区及周边气象站；优先覆盖太湖中心、梅梁湾、竺山湾、西部沿岸和主要饮用水源地附近站点。
- 如 CMA 仅按行政区或格点提供，申请江苏、浙江太湖周边区域及覆盖太湖的 CLDAS 格点裁剪。

### 3.2 时间范围

- 首选：`2019-01-01` 至申请时可提供的最新日期。
- 最低要求：连续 3 个完整年度，并覆盖至少 3 个蓝藻暴发季。
- 若实时/近实时数据需单独授权，请同时申请历史回溯和滚动更新权限。

### 3.3 数据产品与频率

| 产品 | 申请频率 | 用途 |
|---|---|---|
| 中国地面气象基本观测数据 | 3 小时；无法提供时接受日值 | 太湖周边气温、降水、风场和湿度校验 |
| CLDAS 陆面同化分析产品 | 小时或 3 小时；格点裁剪 | 温度、降水、风、湿度、短波/长波辐射驱动 |
| 中国地面气候资料日值 | 日值 | 长期训练、季节基线和缺测交叉校验 |

### 3.4 字段清单

- 站点元数据：`station_id`、站点名称、经度、纬度、海拔/高程基准。
- 时间字段：观测时间、发布时间、时区、数据频率、更新时间延迟。
- 气象字段：气温、气压、相对湿度、风速、风向、降水、短波辐射、长波辐射、日照时数。
- 质量字段：质量码、缺测码、异常/订正标识、单位、产品版本。
- 格点产品附加信息：网格分辨率、坐标参考系、覆盖范围、版本和裁剪方式。

## 4. 数据用途与合规承诺

本申请用于大学生科研和 A23 竞赛，不用于商业经营。数据将用于多源数据清洗、异常检测、缺失值插补、时空对齐、特征工程及蓝藻水华监测预警模型训练。申请人承诺：

1. 遵守中国气象数据网及具体产品的许可、引用和再分发要求；
2. 不擅自公开或转发受限原始文件；
3. 仅在授权范围内制作和共享衍生统计结果；
4. 在报告、代码和演示材料中按要求标注数据来源、产品版本和访问日期；
5. 原始文件只读保存，清洗文件与原始文件分离，并保留质量码和缺测码。
