# 阶段1：文献与变量证据表

> 版本：`v0.1.0`　> 目的：证明变量为什么进入数据字典，不等同于证明来源已经可自动接入。

## 1. 证据等级

| 等级 | 判断标准 | 在本项目中的用法 |
|---|---|---|
| A | 国家标准、官方数据产品、同行评议的太湖长期数据论文 | 可作为数据字段和处理规则的首选依据 |
| B | 同行评议的太湖过程研究或成熟遥感方法论文 | 可作为机理变量、匹配方法和反演指标依据 |
| C | 综述、开源模型文档或跨湖泊研究 | 可作为补充依据，不能单独证明太湖接口存在 |
| D | 二手转载、视频、博客或未审稿材料 | 只用于发现线索，不写入核心科学结论 |

## 4. 第一阶段可得性与科学必要性分离

| 结论类型 | 可以从证据得出 | 不能从证据得出 |
|---|---|---|
| 科学必要性 | 变量被太湖长期研究、过程研究或国家监测规范使用 | 该变量今天一定有稳定API |
| 历史可用性 | 某些论文公开了历史数据、采样频率和匹配规则 | 原始数据可以不经许可直接再分发 |
| 反演方法 | FAI、红边/近红外波段、Chl-a配对和误差指标有研究先例 | 直接套用外湖算法就能得到太湖准确值 |
| 实时能力 | CMA/CLDAS和官方水文门户有实时/业务产品线索 | 竞赛环境一定能匿名访问、无限下载或商业使用 |

## 5. 下一阶段验证清单

对每一个候选数据源，需要在《数据源可接入性验证报告》中补齐：

1. 实际入口或正式下载地址；
2. 是否需要账号、密钥或申请；
3. 请求参数和一个真实响应/文件样例；
4. 字段与本字典的映射覆盖率；
5. 历史起止时间、更新频率和实测延迟；
6. 站点、网格或影像空间范围；
7. 缺失率、异常率、云覆盖率或失败率；
8. 许可、科研/比赛/商业使用和再分发风险；
9. 替代来源和来源切换后的单位/质量差异；
10. 能否按相同配置重复下载，且原始响应可追溯。
