## 1. Luna必须遵守的执行协议

### 1.1 每次只完成一个可验收任务

Luna每一轮按以下顺序工作：

1. 打开本文件和`luna_execution_checklist.csv`；
2. 选择状态为`TODO`且所有依赖已为`DONE`的最小编号任务；
3. 先检查现有代码、用户改动、配置和样例，禁止重复实现；
4. 把该任务状态改为`IN_PROGRESS`；
5. 实现代码或文档；
6. 运行该任务的定向测试；
7. 再运行完整测试`python -m pytest -q`；
8. 保存真实运行证据、manifest和输出摘要；
9. 只有验收标准全部满足才改为`DONE`；
10. 在任务日志中写清改了什么、测试结果、真实数据还是模拟数据、遗留风险；
11. 停止，等待下一次“继续”，不跨越门禁擅自开始后续任务。

### 1.2 禁止事项

- 不得声称未实际运行的接口“已接入”；
- 不得把目录搜索成功写成像元数据下载成功；
- 不得把Open-Meteo开发代理宣传成CMA或ECMWF权威数据；
- 不得把网页公开展示等同于官方机器API；
- 不得绕过登录、验证码、Cookie、动态签名、付费或访问控制；
- 不得在仓库保存账号、密码、Token、OAuth secret；
- 不得把缺失值填0，除非变量语义和质量码明确表示真实0；
- 不得把月度/季度TN、TP重复展开成每日实测；
- 不得插补验证集或测试集目标值后当作真值；
- 不得把卫星估计的藻密度标成显微计数实测；
- 不得删除用户已有数据、修改无关目录或使用破坏性Git命令；
- 不得下载全球整景、整球GRIB或不必要的大文件，必须按太湖窗口裁剪。

### 1.3 每项任务的固定返回格式

```text
任务ID：
状态：DONE / BLOCKED / FAILED
本轮修改文件：
真实输入：
生成输出：
定向测试：
完整测试：
数据真实性：真实接口 / 真实文件 / 官方元数据 / 合成测试夹具
验收结论：
阻塞与下一任务：
```

### 1.4 状态含义

| 状态 | 含义 |
|---|---|
| `TODO` | 未开始 |
| `IN_PROGRESS` | 当前唯一正在执行的任务 |
| `DONE` | 输出存在、测试通过、证据完整 |
| `BLOCKED_AUTH` | 缺账号、Token或书面授权，代码仍可继续做离线适配 |
| `BLOCKED_DATA` | 缺真实样例，无法验证字段/精度 |
| `BLOCKED_POLICY` | 条款或robots不允许自动采集 |
| `FAILED` | 代码/测试失败且本轮没有修复 |
| `SKIPPED` | 经主计划明确批准不做，必须记录原因 |

## 3. 最终完成定义

只有同时满足以下条件，整个数据清洗任务才能标记完成：

1. 至少遥感、气象、水质/藻情、水文四类来源各有一个真实批次；若授权水质仍未取得，允许交付“公开数据版”，但必须明确降级，不能声称实时地面校准完成；
2. 每个批次都有原始响应、请求参数、抓取时间、checksum、许可标签和解析manifest；
3. 所有数据进入统一字段、统一单位、统一时区和统一空间参考；
4. 异常、缺失、插补、代理数据和拒绝数据均可追溯；
5. Sentinel-2/3或CLMS至少形成真实太湖Chl-a/FCBPROB/水华面积输出；
6. 有地面Chl-a时完成遥感校准；无地面样本时输出明确的`uncalibrated`状态；
7. 生成1—3天、7—15天、30—90天三套无未来信息泄漏的数据集；
8. 生成一个版本化SQLite数据库及CSV/Parquet/COG导出；
9. 完整测试全部通过，新增适配器均有离线夹具测试；
10. 至少完成连续7天调度演练，或者用历史回放等价验证；
11. 数据字典、来源报告、部署说明、许可台账、质量报告与实际代码一致。

- 初始检索bbox：`[119.90, 30.90, 120.75, 31.65]`。

- 输入：`aliases.yml`、`variables.yml`、42项来源字段。
- 动作：补齐CLMS、ECMWF、GFS、IMERG、CMA、TBA和HJ1404字段别名。
- 验收：所有P0/P1源的字段均映射到标准变量或明确进入`unmapped_fields.csv`。

### P01-05 单位契约闭环

- 输入：`units.yml`和模型数据字典。

### P01-06 时间契约

- 验收：DST无关但UTC偏移正确；无时区字符串不被静默当UTC。

### P01-07 数据许可字段

- 验收：受限数据导出前可以自动阻止再分发。

### P15-06 文档同步

### P15-07 冻结版本

### P15-08 最终交付包

## 22. 分级交付策略

### A级：公开数据可运行版
