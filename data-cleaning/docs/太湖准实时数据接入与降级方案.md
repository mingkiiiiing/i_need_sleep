# 太湖准实时数据接入与降级方案

## 1. 结论

公开数据能够搭建“准实时监测预警”链路，但不能单独提供连续、小时级、站点实测的叶绿素 a 和蓝藻密度。系统采用两条并行链路：

- 公开运行链：卫星近实时影像、实时/预报气象、公开水质页面、公开水位数据；
- 授权增强链：自动站、浮标、无人机和人工采样数据，用于地面校准与独立验证。

没有授权浮标数据时系统仍可运行，但必须将产品标记为“遥感/模型估算”，不能标记为“浮标实测”。

## 2. 可持续接入的数据源

| 数据源 | 数据内容 | 更新/时效 | 接入方式 | 当前定位 |
|---|---|---|---|---|
| Copernicus Data Space | Sentinel-2 L2A多光谱影像 | 随卫星过境，受云影响 | STAC、OData、Sentinel Hub API | 水华面积与叶绿素代理反演 |
| NASA LANCE | MODIS/VIIRS近实时产品 | 多数产品观测后约3小时 | HTTPS/API，需Earthdata账号或令牌 | 大范围水华快速发现与Sentinel缺测补充 |
| ECMWF Open Data | 风速、风向、气温、降水、辐射等预报 | 00/06/12/18 UTC四个预报周期 | ecmwf-opendata客户端/公开对象存储 | 未来1—15天气象驱动 |
| 生态环境部实时发布系统 | 国家地表水自动站公开指标 | 实时展示 | 官方网页；未确认稳定公开API | 水质观测补充，正式自动抓取前核对使用规则 |

## 3. 运行时数据分层

### L0：真实观测

站点/浮标实测、人工采样和卫星原始反射率。保留原始值，不用插补值覆盖。

### L1：质控观测

经过范围、突变、时序一致性和空间邻站检查的数据。每个值必须携带质量标识。

### L2：估算和插补

遥感反演、时空插值、模型同化结果。字段中记录方法、输入来源和不确定性。

### L3：预报

未来1—3天、7—15天和30—90天的模型输出。不得与观测数据混为一表而不标识。

## 4. 所有记录必须增加的时效字段

| 字段 | 含义 |
|---|---|
| `event_time` | 实际观测或模型起报时间 |
| `ingested_at` | 系统接收时间 |
| `latency_minutes` | 接收时间与观测时间差 |
| `data_age_minutes` | 生成业务产品时数据已经多旧 |
| `value_origin` | observed、remote_sensing、imputed、simulated、forecast |
| `quality_flag` | valid、suspect、invalid、missing |
| `source_id` | 数据提供方和接口标识 |
| `is_realtime` | 是否满足该指标配置的实时阈值 |

## 5. 缺测降级规则

1. 有浮标且质控通过：使用浮标值，并用卫星做空间扩展。
2. 浮标缺测但有无云卫星：使用遥感反演值，显示反演置信区间。
3. 卫星受云遮挡但有历史站点：使用上一时刻状态、气象驱动和水动力/AI模型外推。
4. 两者均无：输出风险概率和不确定性，不输出伪造的实测浓度。
5. 数据超过时效阈值：驾驶舱显示“数据已过期”，不得继续显示为实时状态。

建议时效阈值：

- 自动站/浮标：120分钟；
- 气象预报：最新起报周期不超过12小时；
- 卫星：无云有效观测不超过72小时；
- 公开水位：不超过36小时；
- 营养盐人工监测：只作为慢变量，不标记实时。

## 6. 比赛表述边界

可以表述：

> 系统已接入多源公开准实时数据，并预留授权自动站/浮标接口；在站点缺测和卫星云遮条件下，通过机理—AI模型进行状态外推，同时输出数据时效、来源与不确定性。

不应表述：

> 系统已经获取太湖全部实时叶绿素a和蓝藻密度实测数据。

除非确实取得相应授权接口和真实记录。

## 7. 实施顺序

1. 接通Copernicus STAC，验证太湖范围最新Sentinel-2产品搜索。
2. 接通ECMWF Open Data，落库风速、风向、降水、气温和太阳辐射预报。
3. 接入太湖流域管理局公开水位，并保留页面发布时间和抓取时间。
4. 对生态环境部实时发布页面做可用性与许可核验；没有公开API时不依赖非公开接口。
5. 完成遥感水华面积流水线，将结果标记为`remote_sensing`。
6. 授权浮标文件到达后预检，通过后映射进统一字段并启动校准。
