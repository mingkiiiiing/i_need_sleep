### 2.2 NASA POWER hourly point

请求：

```text
GET https://power.larc.nasa.gov/api/temporal/hourly/point
    ?parameters=T2M,WS10M,WD10M,PRECTOTCORR,ALLSKY_SFC_SW_DWN
    &community=RE
    &longitude=120.30
    &latitude=31.20
    &start=20240601
    &end=20240602
    &format=JSON
```

实际返回：HTTP 200，JSON，48个小时记录（2024-06-01 00:00至2024-06-02 23:00，接口头信息标记为LST时间标准）。

样例：

```json
{
  "location": {"longitude": 120.3, "latitude": 31.2},
  "2024060100": {
    "T2M": 18.77,
    "WS10M": 2.31,
    "WD10M": 211.9,
    "PRECTOTCORR": 0.09,
    "ALLSKY_SFC_SW_DWN": 0
  }
}
```

样例缺失率：5个参数各48条，共240个参数单元；该样例未出现空值或`-999`填充值，样例缺失率为0%。这不是长期缺失率，正式运行必须按日期、位置和参数持续统计。

字段映射：

| POWER字段 | 标准字段 | 单位/含义 |
|---|---|---|
| `T2M` | `air_temperature` | °C，2 m气温 |
| `WS10M` | `wind_speed` | m/s，10 m风速 |
| `WD10M` | `wind_direction` | degree，10 m风向 |
| `PRECTOTCORR` | `precipitation` | 源单位mm/day，清洗时按时间桶转换为累计mm |
| `ALLSKY_SFC_SW_DWN` | `shortwave_radiation` | 源单位Wh/m²，清洗时统一为W/m²或时间桶能量 |

注意：接口提供的是点位/格点大气驱动，不是湖面水温和水质实测；空间上应按站点提取或插值，时间上必须保存产品时间和抓取时间。NASA POWER是气象补充源，不能替代地面水质站。

产品入口：[NASA POWER API](https://power.larc.nasa.gov/)。

## 11. 阶段7遥感指数与地面校准接口

### 11.1 当前可接入范围

阶段7已实现本地Sentinel-2 L2A像元表适配器：输入至少包括场景编号、过境时间、经纬度、B03/B04/B05/B08/B11反射率，以及SCL或水体掩膜、云概率和像元面积。反射率缩放必须由命令行显式传入，例如产品元数据明确为`DN/10000`时才使用`--reflectance-scale 0.0001`，代码不会根据数值大小猜测单位。

当前Copernicus STAC真实验证结果仍是目录HTTP 200和场景元数据，产品波段匿名下载未通过，因此本轮没有生成虚假的真实像元反演结果。真实文件放入`storage/raw/local/`后，使用：

```powershell
python -m pipeline remote-index --input storage/raw/local/sentinel2_pixels.csv --reflectance-scale 1.0
```

### 11.2 指数和质量规则

`remote-index`计算：`NDWI=(B03-B08)/(B03+B08)`；FAI使用B04/B08/B11在665、842、1610nm处的线性基线；MCI使用B04/B05/B08在665、705、842nm处的红边基线。SCL水体代码6、云/阴影/雪代码3/8/9/10/11，云概率默认阈值40%。没有云层或水体层时会降级并增加`Q32`；关键波段缺失增加`Q31`；有效水体覆盖率低于50%的场景增加`Q34`。

输出的`remote_bloom_class`仅为`疑似水华`或`清水`，不代表经过地面验证的蓝藻分类。`remote_chlorophyll_a`在校准前保持空值并标记`Q33`；场景面积只汇总通过有效水体/云掩膜的疑似像元。

### 11.3 地面配对与Chl-a校准

`remote-pair`按时间容差和Haversine距离选择最近地面Chl-a观测，保留`time_gap_hours`、`space_gap_m`和`match_status`。`remote-calibrate`至少需要10个有效配对，按时间排序将最后20%作为验证集，拟合`log1p(Chl-a)`线性校准模型，输出R²、RMSE、MAE和验证残差RMSE。样本不足时返回`blocked_insufficient_ground_truth`，不会写入可用反演系数。

因此，阶段7当前完成的是“可接入、可审计、不可越权推断”的遥感处理链；最终Chl-a/藻密度反演仍取决于Sentinel-2波段文件和同步地面标签授权。

| 对短临P0门禁的作用 | 只能补充历史目标候选，不能替代连续水站/浮标实时值 |

来源证据：[湖泊—流域科学数据中心专题页](https://lake.geodata.cn/feature.html)、[太湖水质数据在线查询系统说明](https://lake.geodata.cn/gxb.html)。

## 19. 阶段16授权水站文件一键入模流水线

在实时水站端点尚未授权的情况下，先把“获得文件后的执行路径”固化为单命令批次：

```powershell
python -m pipeline waterstation-batch --input <授权水站文件> --source-id taihu_water_station
```

`pipeline/waterstation_batch.py`支持JSON/CSV/TSV/XLSX以及`waterstation-fetch`保存的原始JSON信封，按以下顺序执行：

1. 解析生态环境部协议字段和中文/英文别名；
2. 写入独立 `storage/staging/waterstation_<timestamp>/`，避免与历史数据混源；
3. 进入标准化、单位换算、异常/缺失/重复质控和SQLite清洗输出；
4. 执行P0目标、水温、TN、TP、单位、时间、站点和频率门禁；
5. 返回 `ready` 或 `blocked_by_quality_gate`，并写入批次manifest。

本阶段没有使用模拟数据。只有门禁返回 `ready`，才允许继续重采样、时空对齐、因果特征和未来标签；否则批次清单会保留阻断原因，防止低频或缺字段文件被误当成短临训练集。

## 20. 阶段17多文件目录接入与哈希去重

为支持真实业务中的多站点、多日期导出，本阶段增加：

```powershell
python -m pipeline waterstation-batch-dir --input-root <授权文件目录> --source-id taihu_water_station
```

该命令递归扫描JSON/CSV/TSV/XLSX，计算SHA-256并跳过完全重复文件；每个文件的解析状态、标准化行数、变量覆盖、暂存路径和错误原因写入 `input_inventory.csv`。只有解析成功且有记录的文件进入独立staging目录，随后统一执行清洗和P0门禁。解析失败不会静默丢弃，完全重复文件不会重复进入模型数据集。

当前阶段交付的是可直接接收授权文件的工程能力，尚未对真实水站目录做业务运行，因为实时水站账号/导出文件仍未获得。获取文件后，目录清单是判断数据是否完整、是否重复和是否存在格式漂移的第一份审计证据。

## 21. 阶段18清洗质量报告

新增 `quality-report` 命令，对任意一次 `cleaned_observations.csv` 及其同目录的拒绝、待插补和QC问题表生成固定质量汇总：

```powershell
python -m pipeline quality-report --cleaned storage/exports/cleaning_<run_id>/cleaned_observations.csv --as-of 2026-08-18T00:00:00Z
```

报告按来源、变量和单位输出有效值数、缺失率、时间范围、站点数、中位采样间隔、新鲜度、重复键、拒绝/待插补行、质量标志、插补/代理值计数及状态（`available`、`low_frequency`、`stale`、`missing`）。结果写入CSV、JSON、SQLite和Manifest，可直接作为实验切分前的入模证据。

该阶段不改变原始或清洗数据，只生成审计结果；低频、过期或缺失变量不会因为报告生成而被自动标记为可用。

| 赛题来源类别 | 首选来源 | 当前工程证据 | 更新属性 | 对模型的职责 | 当前状态 |
|---|---|---|---|---|---|

### 22.1 合规验收口径

最低可演示组合：

```text
遥感（Sentinel-2） + 气象预报（ECMWF/CMA或有明确来源的开发代理）
```

该组合满足“两类数据源接入”，可完成自动接入、清洗、缺失处理、时空对齐和水华面积代理反演，但不能独立证明叶绿素a或藻密度反演准确。

推荐参赛组合：

```text
遥感 + 气象预报 + 历史/公开地面水质 + 公开水文
```

授权增强组合：

```text
推荐组合 + 太湖自动站/浮标连续实测
```

只有授权增强组合适合宣称“站点实测驱动的实时短临预警”。没有授权水站时，输出必须区分`observed`、`remote_sensing`、`forecast_proxy`、`imputed`和`simulated`。

### 22.2 不能混淆的三个概念

1. `公开发布平台`不一定提供稳定、允许批量调用的API；网页可见只能证明公众可查。
2. `实时`不代表所有指标同频：气象可小时级、水位可日级、卫星按过境、TN/TP通常为日/周/月级。
3. `接入成功`必须有请求、原始响应、抓取时间、字段映射和许可记录；仅有来源链接不算完成接入。

### 22.3 下一接入优先级

1. 把Copernicus从“目录查询”推进到L2A波段实际下载、云掩膜和太湖裁剪。
2. 将开发用Open-Meteo并联/替换为ECMWF Open Data或获准使用的CMA预报源。
3. 对生态环境部实时水质发布系统只使用公开、合规的下载方式；没有文档化API时继续走正式申请或平台导出。
4. 将太湖网当前水位和水情月报作为独立水文源，保存发布时间、抓取时间和水位基准说明。
5. 每日生成接入清单和质量报告，持续统计延迟、缺失率、云覆盖、字段漂移与接口失败率。
