# 太湖蓝藻多源数据全量接入与清洗重构方案

版本：V2.0（2026-08-18）  
范围：仅覆盖“数据寻找、下载/合规采集、接入、质控、插补、时空对齐、特征衍生、反演校准、标准数据集交付”，不包含预测模型和前端页面开发。  
主数据源登记表：[`../config/data_source_registry.csv`](../config/data_source_registry.csv)

## 1. 结论先行

太湖项目不应等待一个“万能实时水站接口”。可落地的数据底座应采用四条并行链路：

1. **准实时遥感状态链**：Copernicus CLMS湖泊水质产品直接提供叶绿素a均值、叶绿素不确定度和漂浮蓝藻概率；Sentinel-2/3负责更高空间分辨率的二次反演与水华面积识别。
2. **预报驱动链**：ECMWF IFS/AIFS和NOAA GFS支撑1—15天；C3S季节预报支撑30—90天；CMA、ERA5-Land、NASA POWER、GPM IMERG用于观测校验和历史训练。
3. **地面真值链**：生态环境部/地方授权水站、浮标和人工采样是叶绿素a、藻密度、营养盐校准的首选；未授权前使用THQBCA、国家数据中心数据和公开论文数据训练历史基线，但必须带来源和不确定度标记。
4. **水文与静态机理链**：太湖流域管理局水位、水利部水雨情、GloFAS代理，以及湖界、流域、DEM、土地利用，形成水动力、入湖负荷和空间传播特征。

因此，“至少2类数据源接入”可以立即由**遥感+气象**满足；为了形成可信的业务预警，正式验收目标应提高为**遥感+气象+水质/藻情+水文**四类。没有实时浮标不会使系统完全无法推演，但会直接降低叶绿素a/藻密度绝对值校准、突发藻华确认和结果可信度，不能用插补值伪装成真实观测。

## 2. 目标、边界与时间语义

### 2.1 数据产品目标

最终稳定输出以下标准产品：

| 产品 | 粒度 | 主要用途 | 建议格式 |
|---|---:|---|---|
| `taihu_observations_long` | 站点×时间×变量 | 原始/清洗后水质、气象、水文长表 | SQLite + Parquet/CSV |
| `taihu_remote_grid` | 网格×成像时间 | 反射率、Chl-a、漂浮蓝藻概率、质量标记 | COG/GeoTIFF + Parquet索引 |
| `taihu_daily_features` | 网格或湖区×日 | 多源融合特征、缺失掩码、数据龄期 | Parquet/CSV |
| `taihu_targets` | 网格/湖区×目标时间 | Chl-a、藻密度/生物量、水华面积、风险级别 | Parquet/CSV |
| `dataset_h1_3d` | 样本×预报起报时刻 | 1—3天训练、验证、推演 | Parquet/CSV |
| `dataset_h7_15d` | 样本×预报起报时刻 | 7—15天趋势预测 | Parquet/CSV |
| `dataset_h30_90d` | 样本×月/旬 | 30—90天概率/趋势预测 | Parquet/CSV |
| `qc_issues` | 问题记录 | 异常、插补、冲突和人工复核证据 | SQLite + CSV |
| `source_health` | 数据源×运行批次 | 新鲜度、成功率、缺失率、许可状态 | SQLite + CSV |

所有返回值必须至少包含：`source_id`、`observed_at`、`ingested_at`、`longitude`、`latitude`、`variable`、`value`、`unit`、`qc_flag`、`imputation_flag`、`uncertainty`、`data_age_hours`、`license_tag`和`lineage_id`。

### 2.2 “实时”分级

| 等级 | 定义 | 可用来源 | 可支持任务 |
|---|---|---|---|
| R0 实时 | 延迟≤1小时 | 授权浮标/水站、部分水雨情 | 藻情确认、短临状态更新 |
| R1 准实时 | 延迟1—24小时 | NASA IMERG Early、部分卫星NRT、公开水情 | 1—3天起报状态 |
| R2 滚动更新 | 1—10天 | Sentinel-2、CLMS 10日水质、CMA滞后观测 | 趋势和空间背景 |
| H 历史 | 固定归档 | THQBCA、数据中心、ERA5-Land、Landsat | 训练、校准、回测 |
| F 预报 | 未来强迫 | ECMWF/GFS/C3S/GloFAS | 1—90天预测驱动 |

不能把“网页当前值”自动等同于实时API，也不能把“10日产品”描述为逐小时监测。

## 3. 数据源总体设计

### 3.1 P0：第一批必须接入

| 来源 | 接入方式 | 核心字段 | 当前状态 | 作用 |
|---|---|---|---|---|
| THQBCA/Zenodo | 公开API与文件 | 水质、浮游植物数量/生物量、气候、水位、FAC、Chl-a | 已下载解析 | 历史基线、标签与校准 |
| Copernicus Sentinel-2 L2A | 官方STAC + 下载授权 | B02/03/04/05/08/8A/11、SCL | STAC已连通 | 10—20 m反演和水华面积 |
| CLMS Lake Water Quality NRT 300 m V2 | Sentinel Hub BYOC + OAuth | `CHLAMEAN`、`CHLAUNC`、`FCBPROB` | 官方目录已验证，凭证待配 | 直接Chl-a与漂浮蓝藻概率基线 |
| NASA POWER | 公开REST API | 温度、降雨、风、辐射、湿度 | 已连通 | 历史气象特征 |
| ECMWF Open Data | 开放对象存储/客户端 | 温度、降雨、风、辐射、云量、气压 | 待编码 | 1—15天主预报强迫 |
| C3S Seasonal | CDS API | 30—90天气象集合预报与hindcast | 待账号 | 中长期概率驱动 |
| 太湖流域管理局当前水位 | 合规网页快照/公开文件 | 水位、时间、站点 | 页面已连通 | 湖容、水动力和滞后特征 |
| 授权水站/浮标 | HJ 1404或文件批次 | Chl-a、藻密度、水温、TP/TN、DO、pH等 | 数据待申请 | 实时真值与校准核心 |

CLMS产品是本轮最重要的补充：官方产品把湖泊水质以100/300 m网格发布，300 m V2包含叶绿素a均值、不确定度和漂浮蓝藻概率；目录可直接读取，像元应通过Process API或云端窗口裁剪，不能下载数GB全球整景。产品信息与接入方式见[Copernicus湖泊水质目录](https://land.copernicus.eu/en/products/water-bodies?tab=lake_water_quality)及[300 m V2 API文档](https://documentation.dataspace.copernicus.eu/APIs/SentinelHub/Data/clms/bio-geophysical-parameters/water-bodies/lake-water-quality/lwq-nrt_global_300m_10daily_v2.html)。

### 3.2 P1：第二批高价值来源

- Sentinel-3 OLCI L2 Water：近每日300 m水色补充，见[官方数据接口说明](https://documentation.dataspace.copernicus.eu/APIs/SentinelHub/Data/S3OLCIL2.html)。
- CMA三小时地面观测、CLDAS和长期日值：作为中国区域权威观测，但需学生/科研实名账号。
- NASA GPM IMERG：30分钟降水和前期累积降雨，Early Run约数小时延迟，见[NASA IMERG说明](https://gpm.nasa.gov/data/imerg)。
- ERA5-Land：1950年至今的小时级历史陆面再分析，见[CDS数据集](https://cds.climate.copernicus.eu/datasets/reanalysis-era5-land?tab=overview)。
- Landsat Collection 2：30 m历史反演与长期回测；官方[M2M接口](https://m2m.cr.usgs.gov/)需EarthExplorer账户。
- 湖泊—流域科学数据中心、国家生态科学数据中心、国家地球系统科学数据中心、CERN：补齐地面水质与营养盐历史真值。
- HydroLAKES、HydroBASINS、WorldCover、Copernicus DEM：湖界、汇水区、土地利用和地形机理特征。

### 3.3 P2：替代、验证和答辩增强来源

- NASA LANCE MODIS/VIIRS：高时间分辨率、较低空间分辨率的云间隙补充；多数NRT产品约数小时可用，见[NASA LANCE](https://lance.modaps.eosdis.nasa.gov/)。
- NASA OceanColor：可取Chl-a和水色产品，但太湖属于高浑浊内陆水体，必须本地校准后使用。
- ESA Lakes CCI：1992—2023湖面温度、水位、水体范围与反射率长期序列；需先确认太湖覆盖，见[ESA Lakes CCI v3](https://climate.esa.int/en/catalogue/a56dba09df8a42ec9fba8b8c7a5e1f69/)。
- GloFAS：15天集合流量和更长期趋势代理，不作为太湖业务水文真值，见[GloFAS预报数据](https://ewds.climate.copernicus.eu/datasets/cems-glofas-forecast?tab=overview)。
- 高分系列：用于高分辨率案例展示，依账户、配额和订单交付，不作为第一版运行必需条件。
- BioTIME太湖浮游植物群落：历史物种/丰度补充，不能替代现时藻情。

完整的40余项源、接口、授权、风险和下一动作见[`data_source_registry.csv`](../config/data_source_registry.csv)。登记表中的`V1_live`表示接口或文件入口已经实际连通；`V2_official`表示官方文档可确认但尚未完成凭证下载；`V3_candidate`仅表示目录候选，未取得具体资源ID前不得宣传为“已接入”。

## 4. 可下载、可申请与可采集的边界

### 4.1 优先级顺序

1. 官方公开API、STAC、对象存储或直链文件。
2. 官方账户/API Key/OAuth授权接口。
3. 官方门户人工下载或在线订单。
4. 公开HTML/PDF的低频合规快照。
5. 任何需要绕过登录、验证码、动态签名或反爬的方式均不采用。

### 4.2 合规采集规则

对生态环境部、太湖流域管理局和水利部公开网页，只在页面条款和`robots.txt`允许时建立快照适配器：

- 固定用户代理并提供项目联系邮箱；
- 当前水情最快10—30分钟一次，普通公告每天一次；
- 支持`ETag`和`Last-Modified`，内容未变不重复存储；
- 原始HTML/PDF完整归档，解析值带页面URL、抓取时间和内容哈希；
- DOM选择器失效、字段数量突变或单位变化时停止入银层，进入人工复核；
- 不逆向私有Ajax接口、不复用浏览器Cookie、不绕过登录或验证码；
- 若条款不允许自动采集，切换为人工导出或书面申请。

公开国家水质自动站具有4小时发布机制，湖库站按建设要求可增加Chl-a和藻密度，但公开网页没有稳定、正式承诺的机器API；因此正式工程应申请授权接口或文件交换，通信结构按[HJ 1404—2024](https://www.mee.gov.cn/ywgz/fgbz/bz/bzwb/jcffbz/202501/t20250126_1101554.shtml)适配。生态环境部对自动站监测项目和发布频次的说明可参见[官方答复](https://www.mee.gov.cn/xxgk2018/xxgk/xxgk13/201810/t20181015_662284.html)。

## 5. 三个预测时域的数据装配

### 5.1 未来1—3天：状态更新 + 短期强迫

起报时刻`t0`只使用`t0`之前真实可获得的数据：

- 最新水站/浮标：Chl-a、藻密度、水温、DO、pH、TP/TN、NH3-N、浊度；
- 最新CLMS `CHLAMEAN/CHLAUNC/FCBPROB`，以及最近无云Sentinel-2/3反演；
- 太湖水位、入湖河流量或代理；
- ECMWF/GFS未来72小时温度、风速/风向、降雨、太阳辐射、云量；
- IMERG前6/24/72小时累积降雨；
- 1、3、7、14天滞后、变化率、滚动均值/极值和数据龄期。

若没有实时地面Chl-a，则允许输出“卫星校准后的Chl-a估计/水华概率”，但产品字段必须标为`target_basis=remote_proxy`，不能宣称为站点实测浓度。

### 5.2 未来7—15天：集合气象 + 缓慢水质状态

- ECMWF IFS/AIFS或GFS逐时/逐6小时预报，生成每天和预报窗累计特征；
- 若具备集合成员，输出中位数、10/90分位、超过风速/温度/降雨阈值的概率；
- 最新地面营养盐按原生频率“保持为最近观测+数据龄期”，不伪造每日实测；
- Sentinel/CLMS最近30天水华面积、Chl-a、FCBPROB趋势；
- GloFAS或本地水文模型作为入湖流量代理，保留`proxy_flag=1`；
- 目标可为日风险概率或7/15天窗口内最大水华面积，不应把十日遥感标签硬拆成每天精确标签。

### 5.3 未来30—90天：季节集合 + 气候态 + 营养盐背景

- C3S季节预报的温度、降水、风场集合和hindcast偏差订正结果；
- 历史同月气候态、极端百分位、上一月/季度营养盐水平；
- THQBCA、ERA5-Land、CMA长期序列形成同季节先验；
- 流域土地利用、上游面积、湖泊水位/库容、历史藻华物候；
- 输出旬/月尺度的风险概率、Chl-a等级或90天内事件概率，而非虚假的逐日确定性浓度。

## 6. 藻类参数反演与校准

### 6.1 叶绿素a

三层结果并存：

1. `chl_a_in_situ`：地面站/浮标/人工采样真值；
2. `chl_a_clms`：CLMS `CHLAMEAN`直接产品，携带`CHLAUNC`；
3. `chl_a_local_retrieval`：Sentinel-2/3或Landsat局地模型结果。

Sentinel-2候选特征包括波段比、归一化差值、红边特征、FAI/MCI及水体/云掩膜；模型基线用线性/指数回归、随机森林/XGBoost和已发表的Landsat太湖算法进行比较。已公开的[太湖Landsat-8叶绿素a BST代码](https://github.com/zgcao/bst_oli)可作为可复现实验基线，但必须在本项目匹配样本上重新率定，不直接照搬参数。

### 6.2 藻密度与蓝藻生物量

卫星不能直接、无歧义地测得“细胞数/L”。优先使用浮标荧光藻蓝蛋白、显微计数或公开藻类数据作为真值；遥感的`FCBPROB`、FAI/MCI、Chl-a和水温/风场仅作为代理特征。训练结果需分别标记：

- `algae_density_observed`：实测；
- `algae_density_estimated`：由校准模型估计；
- `cyanobacteria_probability`：概率，不等同于细胞密度。

缺少藻密度真值时，仍可做水华面积和风险等级推演，但无法可靠给出绝对细胞密度，影响是**直接且高**。

### 6.3 水华面积

推荐双通道：

- 高分辨率：Sentinel-2进行水体掩膜、云/阴影剔除、FAI/MCI或监督分类；像元面积求和；
- 稳定基线：CLMS `FCBPROB`阈值化并做不确定性敏感性分析。

至少给出三个阈值情景（如低/中/高），输出`area_km2_p10/p50/p90`或bootstrap置信区间。面积只在有效观测水面内统计，分母必须同时报告`valid_water_area_km2`和`valid_fraction`。

### 6.4 时空匹配与验证

- 地面—卫星时间差：理想≤3小时；常规上限≤24小时；超限仅用于趋势验证；
- 空间匹配：站点周围1—3个像元或与定位误差相符的缓冲区，使用中位数并报告像元离散度；
- 样本拆分：按年份和站点分组，禁止同一次采样的邻近像元同时进入训练和测试；
- 指标：R²、RMSE、MAE、MAPE/SMAPE、偏差；水华分类增加F1、AUC、召回率；
- 校准记录：算法版本、训练数据版本、波段处理、大气校正、匹配窗口、参数和置信区间全部入库。

## 7. 标准数据模型与存储

### 7.1 分层

```text
Bronze 原始层
  API JSON / HTML / PDF / CSV / GRIB / NetCDF / SAFE / COG
        ↓ 解析、单位映射、质量码保留
```

## 8. 质量控制、插补与一致性

### 8.1 八步清洗流水线

1. **文件/接口检疫**：格式、编码、空文件、压缩完整性、checksum、重复批次。
2. **结构校验**：必需列、类型、时间格式、坐标系、变量别名和单位。
3. **物理范围检查**：按变量硬范围和季节软范围；越界值不直接删除，先隔离。
4. **时间一致性**：重复时间、乱序、未来时间、采样间隔突变、时区统一为Asia/Shanghai并保留UTC。
5. **空间一致性**：站点是否落在太湖/流域内、坐标漂移、栅格是否覆盖有效水面。
6. **单变量异常**：Hampel/MAD、变化率、持续常值、传感器卡死。
7. **多变量/机理一致性**：DO—水温、EC—TDS、TN/TP与分项、降雨—流量、云量—辐射等；Isolation Forest只做辅助标记。
8. **去重、插补、版本化输出**：保留原值、处理值、规则版本和可逆血缘。

质量标记采用位掩码或枚举：`GOOD`、`SUSPECT_RANGE`、`SUSPECT_SPIKE`、`SUSPECT_STUCK`、`SUSPECT_CROSSVAR`、`MISSING_SOURCE`、`IMPUTED_SHORT`、`IMPUTED_MODEL`、`PROXY`、`REJECTED`。

### 8.2 插补规则

| 数据 | 允许方法 | 禁止事项 |
|---|---|---|
| 小时级水温/DO/pH | ≤3个连续步线性、样条或Kalman；较长缺口用模型并给区间 | 长缺口静默前向填充 |
| TN/TP/NH3等低频营养盐 | 原生频率状态空间/多重插补；提供`data_age` | 月/季度值复制成“每日实测” |
| 降雨 | 有效观测为无雨时才填0；可用IMERG/CMA交叉替代 | 把缺失直接当0 |
| 风向 | 转为`u/v`分量插值，再还原方向 | 对0°/360°直接线性插值 |
| 遥感云缺失 | Sentinel-2/3/CLMS跨传感器融合、时空模型、有效比例阈值 | 将上一景复制成当前观测 |
| 标签Chl-a/藻密度 | 训练可做带不确定性的半监督估计 | 测试/验证集标签插补后当真值 |

每条插补数据必须返回`imputation_method`、`donor_source`、`gap_length`、`uncertainty_lower/upper`和`observed_flag=0`。模型训练同时输入`missing_mask`和`data_age_hours`，让模型知道数据不是新鲜实测。

## 9. 时空对齐

### 9.1 标准空间单元

- 站点层：保留原始监测点；
- 湖区层：梅梁湾、贡湖湾、竺山湾、西部沿岸、湖心、东太湖等业务分区；
- 网格层：主网格300 m，与CLMS/Sentinel-3一致；高分辨率10/20/30 m栅格保留原文件并汇总到300 m；
- 流域层：HydroBASINS/地方流域边界用于入湖负荷和上游聚合。

所有矢量统一到EPSG:4326保存交换坐标，同时为面积/距离计算建立适合太湖的投影坐标版本。面积不得直接在经纬度下计算。

### 9.2 标准时间单元

- 原始层保留原频率；
- 短期特征层以小时/日为主；
- 7—15天以日为主；
- 30—90天以旬/月为主；
- 预报表必须分开存`forecast_reference_time`、`valid_time`、`lead_hours`和`ensemble_member`，避免把未来信息泄漏到历史特征。

### 9.3 聚合规则

- 状态变量（水温、Chl-a、DO）：日均、日中位、最大、最小、标准差；
- 通量变量（降水、辐射）：日累计；
- 风：对`u/v`求均值并派生合成风速、主导方向、连续低风时长；
- 水华面积：有效水面像元面积求和，同时报告有效覆盖率；
- 多源同变量不先粗暴平均，先保留独立列，再通过校准权重/误差方差融合。

## 10. 特征工程清单

### 10.1 直接特征

- 水质：水温、pH、DO、EC、浊度/TSS、CODMn、NH3-N、NO3-N、TN、TP、PO4-P、Chl-a、藻密度/生物量；
- 气象：气温、降雨、湿度、气压、风速/风向、短波辐射、日照、云量；
- 水文：湖水位、入/出湖流量、流速、前期水位变化；
- 遥感：反射率、SCL/QA、FAI、MCI、NDWI、NDCI、红边比值、CLMS Chl-a与不确定度、FCBPROB；
- 静态：水深、距岸/河口、湖区、流域面积、土地利用、坡度、经纬度和年内周期。

### 10.2 机理和统计衍生特征

- Monod限制：`N/(K_N+N)`、`P/(K_P+P)`；
- 温度响应：Arrhenius/Q10或最适温度函数；
- 光限制：短波辐射、透明度/浊度和水深组合；
- 稳定/聚集：连续低风小时、风向岸向分量、风应力、表层升温；
- 营养盐结构：TN/TP、DIN、N/P限制类别；
- 前期条件：1/3/7/14/30/90天滞后、滚动统计、斜率、异常值；
- 物候：年内正余弦、积温、历史同日/同旬水华概率；
- 数据可信度：来源数、最近观测龄期、有效像元比例、插补比例、不确定度。

## 11. 接入适配器与运行编排

### 11.1 适配器接口

每个适配器统一实现：

```text
discover(start, end, bbox) -> asset_manifest
download(asset_manifest)   -> raw_assets
parse(raw_asset)           -> canonical_records
validate(records)          -> qc_results
publish(records)           -> silver_tables
health()                   -> freshness/coverage/error/license
```

凭证只通过环境变量或本机密钥存储注入，绝不提交到仓库。建议变量包括：

- `TAIHU_CDSE_CLIENT_ID`、`TAIHU_CDSE_CLIENT_SECRET`
- `TAIHU_CDS_API_KEY`
- `TAIHU_EARTHDATA_TOKEN`
- `TAIHU_CMA_ACCOUNT_REF`
- `TAIHU_WATER_STATION_TOKEN`

### 11.2 调度建议

| 任务 | 调度 | 失败降级 |
|---|---|---|
| 授权水站/浮标 | 15—30分钟 | 最近有效状态+数据龄期，触发告警 |
| TBA/MWR水情快照 | 30—60分钟 | 保留旧值但不改变观测时间 |
| ECMWF/GFS | 每个起报批次 | 主备切换并记录模型来源 |
| IMERG | 每3—6小时 | CMA/ECMWF降雨替代 |
| Sentinel-2/3目录 | 每日 | 等待下一景，不伪造 |
| CLMS LWQ目录 | 每日检查 | 最近产品+`data_age_days` |
| CMA/ERA5历史 | 日/月批处理 | NASA POWER作参考，不覆盖权威源 |
| C3S seasonal | 每月 | 上月集合+气候态，降低置信度 |
| 静态数据 | 版本发布时 | 固定旧版本并记录版本 |

每次运行先写`ingestion_runs=RUNNING`，成功后原子发布；失败不得覆盖上一稳定版本。支持按`source_id + 时间窗`幂等重跑。

4. 高分数据：按科研用途下单，只用于增强，不阻塞第一版。

## 13. 缺数影响和替代矩阵

| 缺失数据 | 可替代项 | 对推演影响 | 决策 |
|---|---|---|---|
| 实时Chl-a | CLMS Chl-a、S2/S3局地反演 | 绝对浓度校准和突发确认下降，高影响 | 可运行但必须标“遥感估计”并扩大区间 |
| 实时藻密度 | 藻蓝蛋白、FCBPROB、FAI/MCI、历史关系 | 无法可靠输出细胞数/L，直接高影响 | 改输出水华概率/面积；继续申请真值 |
| 实时TP/TN | 最近采样+龄期、历史月值、负荷代理 | 短期影响中等，中长期偏差增大 | 不日插值；使用mask和不确定度 |
| 入湖流量 | 水位变化、降雨、GloFAS、本地水文代理 | 空间迁移和负荷预测中高影响 | 代理仅辅助，持续申请水文站 |
| 连续太阳辐射 | ECMWF/CMA/POWER | 影响较低到中等 | 可替代并交叉校准 |
| Sentinel-2受云遮挡 | Sentinel-3、CLMS、MODIS/VIIRS、时空融合 | 局地面积精度下降 | 保留有效覆盖率，不强行补全 |
| 高精度水深/流场 | HydroLAKES估计、公开DEM、简化湖区模型 | 精细输运能力下降 | 第一版做分区/统计模型，后续补测深 |

关键原则是：**输入驱动可用权威代理替代，目标真值不可被无痕插补替代。**

## 15. 验收门槛

### 15.1 接入验收

- 至少2类真实来源完成端到端下载—解析—清洗—入库；项目目标为4类；
- 每个“已接入”源至少保存1个真实批次、请求证据、样例数据和字段覆盖率；
- 受限源必须有申请记录或授权凭证，不用演示数据冒充授权数据；
- 近实时源新鲜度达到其官方发布频率的2倍以内，否则报警。

### 15.2 数据质量验收

- 必需字段结构合格率≥99%；
- 时间、坐标、单位、重复记录全部有自动规则；
- 每个插补值100%带方法、缺口、来源与不确定性；
- 测试集目标插补率必须为0；
- 遥感结果报告有效覆盖率，低于阈值时不发布确定性面积。

### 15.3 反演和校准验收

- 有独立年份/站点测试集；
- 地面—卫星匹配窗口、样本数和空间代表性公开；
- Chl-a同时报告R²、RMSE、MAE和偏差；
- 水华面积至少与人工判读或另一传感器交叉验证；
- 藻密度无真值时不得声称完成绝对值校准。

### 15.4 数据集验收

- 三个时域分别建表，不混用时间粒度；
- `forecast_reference_time`之后的信息不会进入特征；
- 每行包含来源、质量、缺失、龄期和不确定性；
- CSV/Parquet与SQLite抽样值一致，字段字典可机器读取。
