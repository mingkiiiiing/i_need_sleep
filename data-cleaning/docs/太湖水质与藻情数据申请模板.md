# 太湖水质、藻情与水文数据申请模板

适用项目：A23“基于机理和 AI 融合的地表水蓝藻水华监测预警模型设计与实现”

## 一、申请顺序

1. 先在“湖泊—流域科学数据中心”注册，检索太湖数据并提交数据订单，主要申请历史水质、气象、生物和遥感产品。
2. 太湖水质自动站、藻情或未公开水质数据，向生态环境部提交政府信息公开申请。
3. 水位、流量、入出湖水量等水文数据，向水利部太湖流域管理局申请或从其水情年报、月报下载。

水质和水文数据应分别申请，不要把不同主管部门的数据写在同一份申请中。

## 二、申请材料清单

- 学生证或在读证明扫描件：学号可保留，身份证号、家庭住址等无关信息应打码。
- 导师签字或学院盖章的科研数据使用说明/介绍信。
- 赛题通知、项目立项书或参赛证明。
- 本文档中的“申请字段清单”。
- 数据用途承诺书：仅用于科研与竞赛，不转售、不擅自公开原始数据，成果按要求署名引用。
- 申请人姓名、学校、学院、联系电话、邮箱和通信地址。

## 三、生态环境部水质与藻情数据申请正文

### 申请标题

希望以电子数据形式提供，优先格式为 CSV 或 XLSX，字符编码为 UTF-8；如无法提供全部字段，恳请提供现有可公开字段、可用时间范围和数据频率，并说明未能提供部分的原因。如数据量较大，可通过下载链接或移动存储介质提供。

## 五、科学数据中心订单“数据用途”填写文本

用于 A23 大学生科研竞赛中太湖蓝藻水华监测预警研究，开展历史水质、气象、生物及遥感数据的质量控制、缺失值插补、时空对齐、特征工程，以及叶绿素 a、藻密度和水华面积反演/校准。数据仅用于非商业科研和竞赛，不擅自传播受限原始数据，成果将依据平台要求规范引用数据来源。

## 六、建议申请范围

首轮不要申请“太湖全部数据”，建议限定为：

- 时间：优先申请 2019-01-01 至最新可提供日期；至少覆盖 3 个完整年度和水华季。
- 空间：太湖全湖自动站/浮标；如受限，优先梅梁湾、竺山湾、西部沿岸、湖心和主要饮用水水源地附近站点。
- 频率：水温、pH、溶解氧、浊度和叶绿素 a 优先小时级或 4 小时级；营养盐可接受日/周级；水位与流量优先小时/日级。
- 格式：原始值与质控值均保留，并要求质量标识、单位和缺测编码。

## 七、收到数据后的交付检查

把获授权文件放入：

`data-cleaning/storage/raw/authorized_waterstation/`

同时填写同目录中的 `authorization_template.yml`，记录提供单位、许可范围、时间范围、是否允许衍生数据和成果公开。正式清洗前检查：

- 文件不是空模板，且包含真实记录；
- 时间、站点、经纬度、字段单位可以识别；
- 授权文件允许项目成员处理数据；
- 原始文件只读留档，清洗结果另行保存；
- 不把受限原始数据上传到 GitHub 或公开附件。
