# 系统部署与使用说明 V0.1

> **📌 现状指引（2026-09-10）**：部署步骤有效；文中"算法模型交付包 V0.2"为 legacy 对照包，当前主链路为 V0.3 真实数据包（backend/model_runtime_v0_3，接口 `/api/v1/model/v3/*`）。统一口径见 12 号文档。

## 1. 系统组成

当前交付的核心系统组件：

- `modeling_v1`：训练、评估、数据读取、融合和报告；
- `synthetic_augmentation`：数据生成与机制过程模块；
- CLI：`verify/train/run-matrix/evaluate`；
- 输出模型 run 包：`run_config + manifest + predictions + metrics`；
- 可解释性与不确定性模块：`explain.py`、`uncertainty.py`；
- 离线批量预测模块：`predict.py`；
- 前端/孪生材料与 PPT 位于项目对应目录。

## 4. 运行命令

### 4.1 单任务滚动训练

```powershell
python -m modeling_v1.cli train `
  --rolling `
  --data <data_dir> `
  --output <new_output_dir> `
  --task-id T1 `
  --variant bloom `
  --horizon-days 3 `
  --seed 20260907 `
  --stop-after full
```

常用参数：

| 参数 | 含义 |
|---|---|
| `--sample-rows` | 数据源抽样预算 |
| `--max-train-rows` | 训练行数上限 |
| `--max-validation-rows` | 验证行数上限 |
| `--max-test-rows` | 测试行数上限 |
| `--history-days` | 是否启用历史特征 |

### 4.2 只做选择不读测试

```powershell
--stop-after selection
```

用于快速覆盖和阈值验证。

### 4.3 完整 63 矩阵

```powershell
python -m modeling_v1.cli run-matrix `
  --data <data_dir> `
  --runs-root <runs_root> `
  --seeds 20260907 `
  --sample-rows 50000 `
  --max-train-rows 50000 `
  --max-validation-rows 20000 `
  --max-test-rows 20000 `
  --chunk-total 4 `
  --chunk-index 0
```

分片：

- `--chunk-index 0`
- `--chunk-index 1`
- `--chunk-index 2`
- `--chunk-index 3`

进度文件分别写入 `matrix_progress_p0.json` 等。

## 8. 错误与降级

### 8.1 非空输出目录

滚动 run 拒绝复用旧目录：

```text
FileExistsError: rolling runs require a new output directory
```

解决：删除旧残留或换新目录。

### 8.2 缺少测试文件

`verify_run` 会报告缺失：

- `selection_manifest.json`
- `evaluation_manifest.json`
- `test_metrics.json`

### 8.3 数据不可用

- 输入行缺少目标：过滤，不作为负样本；
- 缺特征：训练集拟合插补器；
- 质量过低：记录质量状态，不在模型外伪装。

## 10. 限制

本系统不包含：

- 自动真实短信/邮件外发；
- 真实数字孪生渲染服务；
- 真实业务数据库持久化；

这些属于后续平台集成，需要连接实际部署环境。
