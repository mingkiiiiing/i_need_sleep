```text

模拟/代理/真实分标签 > 混用
```

## 4. 不可声明结论

### 4.1 禁止声明真实精度

以下内容不能声明：

- 太湖真实水华分类准确率；
- 真实 1-3 天预警精度；
- 真实 30-90 天预测能力；
- 真实业务告警效果；
- 将合成测试指标等同于真实现场表现。

### 4.2 禁止声明 10% 融合达标

当前状态：

```text
PASS = 0
FAIL = 175
NOT_APPLICABLE = 14
```

因此：

- 不能写“机理-AI 融合相对单一 AI 提升 10%”；
- 不能只挑选表现好的组合汇报；
- 未达标组合保留 FAIL。

### 4.3 禁止把代理当真实

若材料使用：

- 月尺度代理；
- CLMS 代理；
- 模拟标签；

必须标注：

```text
proxy_only
simulation_only
```

不能作为真实水华分类证据。

## 5. 技术限制说明

### 5.1 数据

- 当前使用 V0.4 合成数据；
- 缺少真实水华时空标签；
- 缺少真实当时可用天气预报；
- 不能在未来实况基础上做“预测”。

### 5.2 事件随机性

合成生成器通过随机门控决定事件：

```text
event = uniform < clip(p + 0.26 × previous_event)
```

因此：

- 高召回时精确率有限；
- 未来完整信息参考也不能实现高精确率高召回；
- 不能把模型 AP 低完全归因于模型。

### 5.3 风险类别

- high/severe 样本较少；
- 部分抽样中 severe 可能缺失；
- 风险任务容易退化为多数类。

### 5.4 融合提升

机理与 AI 在当前输入下读取信息相似，导致融合提升有限。

## 6. 答辩建议

### 6.1 不要这样答

不要只展示最好的几个 3 天结果；
不要把 63 组合简单说成“都成功”；
不要用“准确率”替代任务实际指标；
不要承诺真实预警效果。

### 6.2 建议这样答

先讲：

```text
我们完成了从数据到模型的完整、可审计链路
```

再讲：

```text
发现并修复了旧流程的两个关键隔离问题
```

再讲：

```text
63 个任务×时效全部完成冻结测试
```

最后讲：

```text
当前最接近机理正向价值的是空间任务；
合成数据和真实预报输入限制下，10% 门槛未达到，如实保留。
```
