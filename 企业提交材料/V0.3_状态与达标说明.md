## 4. 诚实披露与遗留问题

1. **门禁 NOT_APPLICABLE 而非 FAIL/PASS**：真实标签月度稀疏（3 航次月 + CLMS 月），8 个可训练组合的冻结测试集行数均 <15（T5-chla test=1，T6-probability test=13）。按主理人裁定记 N.A. 并披露；补足真实标签后重训再评，禁止调口径凑数。
2. **遥感校准 R² 偏低/为负**：modis_lwq300 R²=0.056；S2 MCI（择优）R²=−1.21。反演值仅作派生口径，页面全程披露"校准/反演值不作为观测真值"。
3. **栅格无锚点月面积偏大**：2020-12 / 2022-12 / 2023-10 无月度锚点，仅年度基底（边界面积 1248 / 2147 / 1673 km²）；2024-09 起锚点修正后面积合理。
4. **T2/T3/T4/T7 及 30/60/90 天全部不可训练**：属标签密度问题而非算法问题；availability_matrix 逐项给出原因。
5. V0.2 包（63 模型，合成训练边界）完整保留为 legacy 对照，供能力对比与一键回退。
