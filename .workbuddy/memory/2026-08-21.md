# 2026-08-21 工作日志

## 地图性能优化：锁定太湖流域 (已完成)
- 问题：原 Leaflet 地图加载全球卫星瓦片，用户可缩放/随意拖拽到世界任何区域，性能浪费
- 改动 `LakeMap.vue`：
  - 新增 `LAKE_BOUNDS`（太湖流域边界 [30.86,119.80] ~ [31.60,120.50]）
  - 地图 `maxBounds` + `maxBoundsViscosity: 1.0` 锁死拖拽范围
  - `minZoom = maxZoom = 11` 锁死缩放，`zoomControl: false` 移除缩放按钮
  - 禁用 scrollWheelZoom / doubleClickZoom / boxZoom / keyboard / touchZoom
  - 三个瓦片层加 `bounds: tileBounds` 限制，区域外不发瓦片请求
  - `fitBounds()` 改为 `setView(LAKE_CENTER, FIXED_ZOOM)` 固定居中
- 效果：瓦片请求从"全球可缩放"降为"太湖固定视角约 6-12 块瓦片"
- 构建通过 (944KB bundle)

## 地图"占画布太小"修复 (已完成)
- 问题：用户反馈地图只占画布一部分，不如最初全球地图饱满好看
- 根因：`computeFitZoom()` 里 `Math.round(z - 0.6)` 减档 bug，把 zoom 从 10 掉到 9，视野 4 倍，太湖只占画面 1/4
- 修复：
  - `Math.round(z - 0.6)` → `Math.floor(z)`，去掉减档 bug
  - `LAKE_EXTENT` 收紧 padding：[30.92,119.92] ~ [31.52,120.40]，太湖占画面更大
  - 恢复有限缩放：`minZoom = fitZoom`，`maxZoom = fitZoom + 2`，重新开启 zoomControl / scrollWheelZoom / doubleClickZoom / touchZoom
  - maxBounds 仍锁太湖流域，性能不受影响
- 教训：Leaflet `getBoundsZoom` 返回已保证装下 bounds，做 padding 减法再取整会掉档

## 地图缩小露白修复：边界扩至长三角 (已完成)
- 需求：缩小到 9 级时只有太湖流域有地图，流域外空白影响观感，要让外面也被地图填充
- 改动 `LakeMap.vue`：`LAKE_BOUNDS` 从太湖流域 [30.86,119.80]~[31.60,120.50] 扩大到长三角 [29.30,118.00]~[33.10,122.30]
- 三个瓦片层 `bounds` + 地图 `maxBounds` 都引用同一常量，自动跟随扩大
- 原理：9 级宽屏视野约 4.5°×3.8°，新边界可保证满屏瓦片；瓦片请求量仍取决于视口大小而非 bounds 大小，性能不受影响
- 默认视图（11 级太湖）、LAKE_CENTER、缩放范围 9-14 均不变
- 构建通过
