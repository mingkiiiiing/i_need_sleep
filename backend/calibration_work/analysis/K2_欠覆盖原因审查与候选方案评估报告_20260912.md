## 0. 结论速览

1. **T+1 欠覆盖是真实的且可部分归因**：二项检验 p=0.0074 显著低于 88% 线。主因是**测试段含校准段完全不代表的子总体**（ground_truth 野外实测 42 行 + 非季测月 41 行），该子总体覆盖仅 66.7%，而与校准段同口径的子总体覆盖 86.7%。这属于分布偏移（H1）+ 代理标签外推（H5），**不是现有分位数构造方法能修复的部分**。
2. **T+90 的"欠覆盖"（85.47% vs 88%）在 n=117 下统计上不可判定**（二项检验 p=0.236）；其中心无偏（H2 否）、分布无漂移（H1 否）、OOF/val 两池分布检验不出差异（H3 否），最薄弱环节是 **P95 尾部估计本身极不稳定**（bootstrap CI [6.09, 11.97]，宽 5.9 μg/L，H4 是）。
3. **"混合残差池"假设（H3）经检验不成立**：T+1/T+90 的 OOF vs validation 残差 KS 检验 p=0.18/0.27，Brown-Forsythe 方差检验 p=0.66/0.89，均不显著。K1-06 观察到的分池覆盖率差异（90.9% vs 77.3%）量级与 H4 的分位抽样波动一致，主要归因分位估计不稳定，而非两池系统性分布差。
4. **候选方案回测：C（位置-尺度）相对最优**（4 个回测配置全部 ≥88% 且宽度最窄档），但回测段全部由"校准段同口径"行构成，**无法验证对未见子总体的改善**——因此没有任何候选能凭本轮证据证明可把测试段总体覆盖率拉到 88%。**本轮不建议接入**；C 仅作为下轮候选保留，接入前置条件是冻结段（2024+）外层验证。
5. 手工放大对照（×1.15/×1.30）在回测段**没有换来覆盖增益、只增加宽度**——"宽度换覆盖"得到实证，维持红线 5。

## 3. 假设检验 H1~H5（任务2，`k2_hypothesis_tests.json`）

结论表（不直接定根因，逐假设给判定）：

| 假设 | 支持证据 | 反对证据 | 可否判定 |
| --- | --- | --- | --- |
| **H1 分布偏移**（测试段季节/幅度与校准段不同 → 分位不适配） | T+1：季节 p=7.2e-18、湖区 p=2.5e-14、残差 KS p=2.7e-4 均显著；**反事实**：与校准段同口径子总体（proxy∧季测月∧9 常规单元，n=90）覆盖 86.7%，未见子总体（n=42）仅 66.7%——欠覆盖 13.6pp 缺口中约 2/3 由子总体外推解释。幅度偏移方向一致但仅边缘（p=0.052） | T+90：季节/湖区/幅度/残差全部不显著（p=0.55/1.0/0.51/0.21），却仍差 2.5pp 未达标——分布偏移不是 T+90 的原因 | **T+1 成立（主因级别）**；**T+90 不成立**。H1 应精确表述为"校准段对测试段**子总体构成**的外推"，而非连续幅度漂移 |
| **H2 模型偏差**（残差中位显著偏离 0 vs 仅尾部不足） | T+1：测试残差中位 −2.04，Wilcoxon p=2.0e-8 显著；**校准池自身中位也 −0.80（p=7.0e-6）**——模型整体性轻微高估，测试段加重。破界不对称 21 低/5 高。反事实分解（诊断）：原始 80.3% → 仅修位置 88.6% → 仅修尺度 90.9% → 双修 89.4%：**位置与尾部各有贡献，尾部贡献更大** | T+90：中位 −0.31（p=0.96）无偏，破界 10/7 对称；按 std 拉平做尺度修正覆盖率反而降至 81.2%（测试段残差离散并不比校准池大）→ T+90 的问题是 P95 估计不稳定（见 H4），不是模型偏差 | **T+1 部分成立**（中心偏移 + 尾部不足并存，两者都不是唯一根因）；**T+90 不成立** |
| **H3 混合残差池**（OOF 与 validation 残差分布不同 → 混池分位被拉宽/拉窄） | 结构性疑虑真实存在：OOF 残差出自 early-only 折模型（训练数据约为最终模型一半），validation 残差出自全 train 装配模型，两池**不同源**，严格说破坏 split-conformal 可交换性；T+90 OOF std 5.25 vs val 3.83 方向性偏大 | **两槽位 KS 检验均不显著**：T+1 p=0.184、T+90 p=0.266；Brown-Forsythe 方差检验 p=0.659/0.895 亦不显著。K1-06 的分池覆盖率差（90.9% vs 77.3%）对应的 P05 差（−6.24 vs −4.50）落在 H4 bootstrap CI（宽 2.7）量级内，**用分位抽样波动即可解释，无需两池分布不同**。回测旁证：A1（OOF-only）与混池 BASE 在回测段差异 ≤1 行 | **不成立（在本样本量下未能证实）**。混池的结构性缺陷保留为理论疑虑，但**不构成改分位数的依据**；K1-06 观察的主要解释权归 H4 |
| **H4 有限样本**（n=234/225 下 5%/95% 分位估计方差大） | bootstrap（2000 次）：T+1 池 P05 CI [−6.85, −4.13]、P95 CI [3.14, 5.81]，各宽 **2.7 μg/L**（现值 −5.58/4.41 仅为其中一点）；T+90 P95 CI [**6.09, 11.97**]，宽 **5.9 μg/L**——T+90 上界"虚高"的空间极大。二项检验：**T+1 106/132 p=0.0074 显著低于 88%；T+90 100/117 p=0.236 未显著**。季节层 bootstrap：夏季层 P95 CI 宽 9.2（T+1）/14.3（T+90）——**分层后分位几乎不可估计** | 无实质反对证据；唯一澄清：T+1 的覆盖噪声带（校准 bootstrap→固定测试残差）为 [75.0%, 92.4%]，观察值 80.3% 在带内——但二项检验表明**真覆盖率低于 88% 本身显著**，两者不矛盾（噪声带说明单点覆盖数字不能精读，二项检验说明"欠覆盖"不是运气差） | **成立（两槽位，T+90 尤甚）**。T+90 的"85.47% FAIL"按现行工程判据记账，但其统计显著性不成立，改善动作的必要性应据此降级 |
| **H5 代理标签**（proxy 标签噪声影响残差分布） | T+1 测试段内部对照：ground_truth 覆盖 66.7% vs proxy 86.7%（同模型同分位），残差 KS p=1.1e-16，gt 残差中位 −3.68 vs proxy −1.09，gt 破界 14 低/0 高。校准池 100% 代理 → 校准分位对 gt 子总体是**纯外推** | 归因不唯一：gt 样本 actual 中位 3.07 vs proxy 6.68，幅度与空间单元都不同——无法区分"模型对野外子总体高估"与"代理标签 vs 实测标签口径差"（二者混在一起）。T+90 无 gt 对照 | **T+1 成立但不可完全归因**（欠覆盖高度集中于 gt 子总体是硬事实，机制二选一待专项）；**T+90 不可检验（盲区）** |

### 与 L-cal-13 的对应

L-cal-13 列出的四个待检验假设中：分布偏移（T+1 成立/T+90 否）、模型偏差（T+1 部分/T+90 否）、混合残差池（**未证实**）、有限样本（成立）——四个假设没有一个是两槽位通吃的单一根因；另补充第五个假设（代理标签外推），它是 T+1 的主要可解释成分。

## 4. 候选校准方案离线评估（任务3，`k2_candidate_backtest.json`）

### 4.1 回测协议（事先固定，写在 03 脚本文件头，未做迭代调参）

- **外层回测段** = K1 池中 validation 行按目标月取最后 12 个日历月：T+1 → 2017-08~2018-05（36 行）；T+90 → 2016-11~2017-08（36 行）。敏感性 K=24（各 72 行）。**绝不触碰 CV test 段**（03 脚本不读 `test_predictions.csv`）。
- **内层校准数据** = OOF 全部 + validation 减去回测段（T+1：198 行；T+90：189 行）。所有候选分位数只在内层数据上估计，回测段只用于评分。
- 评分口径与 serving 一致（chla 下界裁 0）。固定选型规则："回测段覆盖率 ≥88% 中宽度中位最小"。

### 4.4 回测能回答什么、不能回答什么（关键限制）

1. **回测段全部由校准段同口径行构成**（代理标签+季测月+9 常规单元）——欠覆盖重灾区（ground_truth/野外/非季测月）在回测段中不存在。因此回测无法验证任何候选对测试段**总体**覆盖率的改善（T+1 测试段 80.3% 的缺口约 2/3 来自该子总体）。
2. 回测段上 BASE（现行方法复现）本身即过线（91.7%/97.2%）——回测段**不能复现**测试段的欠覆盖严重度，只能做候选间相对比较。
3. 候选间差异普遍仅 1~2 行（3~6pp），n=36/72 时 SE≈5.4/3.6pp——固定选型规则在四个配置给出四个不同答案（T+1: C→A1；T+90: D1→A2），**选型统计上不稳定**。
4. "宽度最小"规则天然偏向贴线候选；且存在回测-测试反向风险：A1 在回测段过线，但 K1 移交的观察（仅观察、非选型依据）显示其在真实测试段最差（77.3%）——**在存在子总体外推风险时，回测选窄区间候选是危险的**。

### 4.5 不做手工放大上下界的对照说明（任务4）

X115/X130（B1 分位双侧放大 15%/30%）在 T+1 主回测段覆盖率 94.4%→94.4%（**一个破界都没修复**），宽度中位却 +15%/+24%（10.84→12.45/13.45）；T+90 段同理（覆盖 97.2% 持平，宽度 +15%/+30%）。即：**手工放大是纯粹的"宽度换覆盖"，且在本数据上连覆盖都没换来**，只会压低区间业务信息量（chla 区间直接决定风险等级带，区间越宽等级带越宽直至失去意义）。红线 5 维持，X 系列任何数值不得接入。

## 5. 接入建议与预估风险

**建议：本轮不接入任何候选校准方案**（与台账收盘规则一致），理由：

1. **T+90 无接入必要**：85.47% vs 88% 未通过二项检验（p=0.236），"欠覆盖"未被统计确证；其真 P95 不确定带 [6.09, 11.97] 意味着任何基于当前 n=117 校准池的"更准分位"都不可信。换分位构造法不解决样本量问题。
2. **T+1 的缺口主因不是分位构造**：约 2/3 缺口来自校准段从未见过的子总体（H1/H5），换任何全局分位法都修不了；同口径子总体内现行为 86.7%（n=90，与 88% 统计不可区分）。
3. **回测验证能力不足**：回测段不含未见子总体、候选差异在噪声内、选型不稳定——当前证据链不满足审查 §4 第三阶段"独立验证达标后发布"的前提。
4. 若下轮继续校准实验：**候选 C（位置-尺度）作为首选保留**——它是唯一在 4 个回测配置全部 ≥88% 且宽度处于最窄档的候选，方向与 H2 结论（中心偏移+幅度相关异方差）一致，且实现简单可追溯；候选 B1（有限样本修正）作为低风险微调可一并考虑。**接入前置条件**：①补冻结 2024+ 段外层验证；②野外/ground_truth 子总体专项（样本来源与标签口径）有结论；③校准产物版本化与快照刷新机制就绪（审查 §4 第三阶段清单）。

**预估风险**：任何候选在真实测试段的覆盖率变化不可预测（回测盲区直接 inherited）；窄区间候选（A1 类）对子总体外推最脆弱；C 的 σ̂ 外推在高预测值区依赖线性假设（预测 >15 μg/L 处无回测覆盖）；T+30/60 季节基线与其余四组（密度/生物量）未在本轮范围，其欠覆盖机制可能不同，不得类推。
