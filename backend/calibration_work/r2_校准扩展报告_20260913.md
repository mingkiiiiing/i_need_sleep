## 5. 新 gate 2 条 PASS 的单类别证据包要点（供 R5 与评委引用）

新 gate_table（2 PASS / 28 FAIL / 12 NA）仅有的两条 PASS——T1-bloom h90 与 T6-probability h90——是**同一段测试上的同一族比较**（brier 完全同值），证据包（`r2_h90_single_class_evidence.json`）要点：

1. **测试段 28 行全阴性**：`runs/T1-bloom-90d-3m-cv/test_predictions.csv` 28 行 `actual` 唯一值 = {0.0}，正例数 = 0；预测决策唯一值 = {0}（全负类）。输入月 2024-11..2026-03，对应 T+90 目标月 2025-02..2026-03（CLMS 代理标签，冬春季无水华阳性）。T6-probability-90d-3m-cv 完全同构。
2. **brier 退化为 mean(prob²)**：全阴性段上 brier 只度量"概率够不够低"。融合（constrained_blend）0.01534 vs gate 比较对象 RF 0.03501 → uplift 0.5619；但同段 **xgboost brier=0.00338，比融合低 4.5 倍**（gate 的单模型比较对象按 validation 选族定为 RF），climatology_global 0.03783、simple_baseline 0.05233。即该 PASS 既建立在单类段上，其比较对象选择也非同段最优。
3. **判别力指标不可定义**：单类段上 roc_auc / pr_auc 为 None（`training_real.probability_metrics:117` 要求 0/1 双类），uplift 的判别力语义无法在该段验证。
4. **gate 层无类别支持检查**：`gate.py build_gate_table`（:109-124）仅判 `test_n >= 15` 且 `uplift >= 0.10`；而运行层 `algorithm_models._calibration_verdict` 对 binary/probability 已有 `class_support → single_class_test` 判定。**两层口径不一致**，这正是 2 条 PASS 应补 `single_class` / `weak` 标记的直接依据。
5. **建议**：该 2 条 PASS 在交付材料中标注 `single_class_test / weak`（平凡比较），不作为"融合族判别力达标"的证据；gate.py 是否补 class_support 检查属代码改动，本轮只交证据包不动代码（红线）。
