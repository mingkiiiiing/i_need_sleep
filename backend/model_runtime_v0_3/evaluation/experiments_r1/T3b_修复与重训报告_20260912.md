## 3. Bug2 T6 序数评估缺陷（L-diag-02）——已修复

**根因**：`train_run_real` 评估循环对 actual 统一 `pd.to_numeric(errors="coerce")`，序数字符串标签（none/low/…）全转 NaN → `ordinal_metrics` 产出幻影类 `'nan'`，与任何预测类不相交 → 全族 macro_f1=accuracy=0 → L-gate-35/37/39/41/42 假 FAIL，validation 同 bug → simple_baseline 平 tie 当选。

**diff 摘要**：新增 `eval_actual_values(frame, spec)`——ordinal 分支保留原始字符串（`astype(str)`），数值任务口径不变；validation 与 test 两处评估调用点改用之。连带修复 `simple` 基线 ordinal 分支（旧代码先 `to_numeric` 再取众数，全 NaN 后兜底成 "none" 的假口径）与 `_fit_oof_residuals` ordinal 短路（字符串预测转 float 原走异常路径）。

**自证数字**（T6-risk_level mo0 真实监督表，训练期内 60/20/20 时间分块，seed=20260907）：

| 项 | 旧评估口径 | 修复口径 |
| --- | --- | --- |
| validation actual NaN 率 | **1.00**（全 NaN 复现） | 0（字符串直通） |
| 同路径 RF test macro_f1 | **0.0** | **0.297**（bug3 修复后标签口径）/ 0.319（污染标签口径），accuracy 0.53 |
| 自预测 sanity macro_f1 | 不可达 | 1.0 |

**重训面板验证**：T6 时间分块面板（n_test=132，5 类标签）macro_f1 全族非零：RF 0.2957 / XGB 0.2654 / mechanism 0.1988 / climatology 0.1942 / simple 0.1221。**5 条 L-gate-35/37/39/41/42 假 FAIL 的"全零"现象已消除；复测结论见 §6 表（macro_f1 口径下融合族均未超过 RF）。**

## 4. Bug3 chla 双单位混用（L-data-05）——已修复

**根因**：water_quality.parquet 的 chla 83 行 = taihu_field_samples mg/L 41 行 + ug/L 41 行（同 (station,month) 成对且严格 ×1000 同值）+ taihu_water_quality mg/L 1 行（S1 0.03 mg/L）；`load_label_wide` / `load_field_chla_samples` 直接取 value 聚合，mg/L 量纲数值被当 μg/L 混入 → 野外月标签≈真实一半 → 代理锚点拉低 → 全部代理标签系统性偏低 → bloom 阳性稀缺。

**diff 摘要**：新增 `_normalize_chla_units`：unit=="mg/l" 的 chla 行 ×1000，统一改写 unit="ug/L"；其余指标不动。**选择"单位统一换算"而非"同值异单位去重"，理由**：1) unit 是清洗层显式权威标注，可编程判定，不需值域启发式；2) 换算对全部 chla 行成立——去重只能处理严格成对行，孤行（S1 0.03 mg/L=30 μg/L）的量纲错误仍会漏网；3) 统一后与 `BLOOM_THRESHOLD_UG_L`/`RISK_BANDS_UG_L`（μg/L）一致。unit 缺失行按原值保留并计数（当前数据 83/83 行 unit 齐全，无此情形）。

**修复前后对照**（同进程复现旧口径 vs 修复口径，与 T1 审计官方数字吻合）：

| 量 | 修复前（污染） | 修复后 |
| --- | --- | --- |
| IN_SITU_GROUP 2020-12 月标签（μg/L） | 3.0651 | **6.124** |
| IN_SITU_GROUP 2022-12 / 2023-10 | 1.1254 / 5.1146 | **2.2485 / 10.2189** |
| S1 2026-08 | 0.03（量纲错误） | **30.0** |
| chla 代理锚点 chla_mean_ug_l | 3.0651 | **6.124** |
| T5-chla mo0 actual 均值（μg/L） | 7.21 | **14.45** |
| T1-bloom mo0 阳性 train/val/test | 23 / 0 / **1** | **133** / 0 / **2** |
| T6 训练段风险带分布 | none 454 / low 110 / medium 17 / high 5 | none 244 / low 210 / medium 83 / high 43 / **severe 6** |

- 阳性稀缺根因消除：训练段阳性 23→133；test 阳性 1→2（S1 2026-08 30 μg/L 经正确换算进入阳性）。
- **validation 仍 0 阳性（31 行）**：2022-12/2023-10 航次实测 2.25/10.22 μg/L 本就低于 20 阈值，非污染所致——L-data-06（validation 单类→选族失真）**不因本修复关闭**。
- 注意：S1 30 μg/L 属 high 带；`sdd` 指标亦存在双单位（m/cm），不在标签/特征契约内，未处理（如实披露，建议数据清洗包核查）。
