## 4. 单类别 PASS 正式定性（口径 F1/F3）

对象：gate_table 仅有的 2 条 PASS——`T1-bloom-3m-s20260907-cv`（h90）与 `T6-probability-3m-s20260907-cv`（h90），n_test=28，uplift≈0.5619。

### 4.1 事实核对（来自 runs 测试产物）

1. **actual 全 0**：两 run 的 `test_predictions.csv` 各 28 行，`actual` 唯一值 `[0.0]`、求和 0——测试段为单类别（全阴性）。月份跨 2024-11~2026-03，共 16 个月 28 行。
2. **fusion vs best_single 的 brier**：
   - fusion（constrained_blend，validation 最优融合族）brier = **0.015339791855464259**；
   - best_single（random_forest，validation 选族：RF 0.1571 < XGB 0.1698）brier = **0.03501296131635124**（T1）/ 0.035012961316351225（T6p，浮点末位差）；
   - uplift = 0.5618824778…（两行同值）。
3. **单类别旁证**：两 run `test_metrics_by_family.json` 全部 8 族 `observed_frequency` 恒 0.0；`f1/precision/recall/roc_auc/pr_auc` 全 null；`uncertainty.json` 的 `empirical_coverage_test=1.0`（全负标签下区间 [max(p+p05,0),…] 恒覆盖 0，覆盖率平凡 100%）。两 run 测试表数值逐行相同（sha 不同仅浮点末位）。
4. gate 的 validation 选族设计本身正确（single 按 validation 在 RF/XGB 中选，未在测试段挑优；测试段 xgboost brier 0.00338 低于 fusion，未被选用恰是防泄漏机制在起作用）——问题不在选族，而在**测试段单类别未做任何检测与披露**。

### 4.2 正式定性

依"测试集单类别不机械算百分比"与口径 F3（单类别必须显式标记、不作为达标证据）：

> **定性：T1-bloom h90 与 T6-probability h90 的 2 条 PASS 应标 `single_class_test`（weak），不构成 10% 硬指标达标证据。**
> 理由：全负标签下 brier 退化为 mean(p²)，任何系统性压低预测值的族都"占优"；fusion 与 single 的差异（0.0153 vs 0.0350）只反映两者预测概率的压缩程度，不含任何正类判别信息，uplift 0.5619 属平凡可比值，不满足"机械算百分比"的前提。同理，该测试段衍生的覆盖率 100% 与"通过 88% 验收线"的表观结论（见 R5-03）均为平凡值。
> 总体门禁结论未因此翻转（2/30=6.67% < 90%，acceptance 仍 FAIL），但 2 PASS 作为"提升证据"在 gate_table、acceptance/detail、快照 acceptance 三处均**无任何单类别披露**（single_class/单类别/degenerate/all_negative 等关键词全响应 0 命中）。

### 4.3 serving 端后果（比 gate 数字更实质）

T6-probability h90 的平凡 100% 覆盖率经四条件合同判定为 `validated` → 站点快照 T+90 `probability` 现在 `value_origin=v0_3_real_bundle`、`decision_usable=true`、逐站响应（旧包为全湖常量/无响应）。即：**单类别平凡覆盖率实际驱动了 T+90 概率层与风险等级范围的服务行为**。
