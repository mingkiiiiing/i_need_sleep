# 请审查并给出完善建议：蓝藻水华预警系统"时空推演结果面板"三标签重设计

## 背景
技术栈：Vue 3 `<script setup>` + 手写 SVG/CSS 可视化（无图表库）。右侧结果面板宽约 280-500px。
数据来源（后端已固定，不可编造）：
- 9 个预测任务（水华/叶绿素a/面积/覆盖率/密度/生物量/风险等级/风险概率/空间），每个任务带：
  - value（数值）与 value_origin（真实模型 v0_3_real_bundle / 叶绿素推导 derived / legacy 合成对照 legacy / 不可用 none）
  - uncertainty：split-conformal P05/P95 + coverage（目标90%、经验覆盖率、校准样本数、测试n，可为 null）
- mechanism_drivers：机理净生长率分解（温度/光照/磷/氮适合度 0-1 + 限制因子 + 净生长率 -0.16~0.6），恒可用
- input_provenance、granularity、quality_gate（ok/partial/degraded/unavailable）
- MEE 实测：叶绿素a/水温/总磷/总氮实时值

## 三个标签页的当前设计
1. 结果总览：焦点指标 hero（大数字+风险概率SVG环+风险带彩色刻度条+游标）→ 质量门chip+一句话理由 → 六宫格指标卡（名称/值/彩色迷你条/来源徽标）→ 叶绿素"预测 vs MEE实测"双横条对照 → 追踪chips行（运行ID/快照/实测字段/粒度/门禁FAIL）→ 可折叠详情 → MEE实测参考。
2. 驱动因素：机理驱动因子分解（4条适合度彩条+来源标注+限制因子红色callout+净生长率双区条含零轴）恒可用；模型敏感性排序仅在模型对输入有真实响应时展示（常数基线模型缩成一行灰字说明）。
3. 不确定性：split-conformal 区间刻度尺（风险带彩色底+P05/点/P95+实测落点标记，纯SVG）→ 分位数网格+区间宽度（含相对%）→ 覆盖率SVG环（达标绿/偏离橙/未核算灰）→ 9任务区间可用性矩阵（按来源色分+宽度条）→ 口径注；legacy 任务退回"输入扰动情景分布"列表。

## 诚实边界（约束，不可违反的建议请直接不提）
- 禁止建议伪造数据/分布（如无分布数据时画正态曲线）；禁止把情景推演表述为真实预测；
- legacy 合成对照任务必须保留来源徽标；常数基线模型不能假装有敏感性排序。

2. 具体可落地的改进建议（给到组件结构/视觉编码级别，不要泛泛而谈）；
3. 代码级问题（性能/边界/可访问性）；

function bandSegments(domainMax) {

def _mechanism_drivers(self, observed: dict[str, float], context: dict[str, float]) -> dict[str, Any]:

        温度再回退 MEE 实测水温（代理口径，逐项披露）。磷/氮条件优先 MEE 实测。
        """
        def clip01(value: float) -> float:
            return float(min(max(value, 0.0), 1.0))

        met_month = None
        temp = context.get("met_air_temperature_c")
        light = context.get("met_shortwave_radiation_wm2")
        # 冻结中位数（与模型推理路径一致：TAIHU_WHOLE 上下文无气象列，模型实际接收的

            met_rows = whole.dropna(subset=["met_air_temperature_c", "met_shortwave_radiation_wm2"]).sort_values("month")
            if len(met_rows):
                row = met_rows.iloc[-1]
                met_month = str(row["month"])
                temp = float(row["met_air_temperature_c"])
                light = float(row["met_shortwave_radiation_wm2"])
        temp_proxy = False
        if temp is None:
            summary = self.realtime.summary()
