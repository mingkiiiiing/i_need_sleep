# 项目概要介绍 V0.1

## 1. 项目名称

基于机理和 AI 融合的地表水蓝藻水华监测预警模型设计与实现

## 2. 项目背景

蓝藻水华是富营养化水体在水文、气象、营养盐共同作用下形成的生态灾害。传统“人工采样 + 实验室分析”难以满足提前预警、精准防控要求。

当前预警技术正在从单一机理驱动转向“机理 + 数据”融合：

- 机理模型可以表达藻类生长、死亡、迁移和营养盐响应；
- AI 模型可以捕捉多源数据中的复杂非线性关系；
- 两者融合有望同时获得物理可解释性和数据适应性。

## 3. 项目目标

面向重点湖库蓝藻水华防控场景，构建完整闭环：

```text
多源感知
→ 数据治理
→ 机理过程模块
→ AI 算法
→ 机理-AI 融合
→ 多时间尺度预测
→ 可解释性与不确定性
→ 风险分级预警和孪生展示
```

## 4. 解决的核心问题

### 4.1 多源数据融合与质量管控

- 遥感、水质、气象、水文数据来源不同；
- 时间、空间、单位、精度不同；
- 需要统一接入、清洗、插补、对齐、质控和版本管理。

### 4.2 机理与 AI 架构差异

- 机理模型以过程方程为核心；
- AI 模型以数据映射为核心；
- 需要设计公平、可审计的融合接口。

### 4.3 多时间尺度

- 1-3 天：短期预报；
- 7-15 天：趋势预测；
- 30-90 天：长期风险研判。

### 4.4 可解释性与业务可信

- 黑箱输出难以被管理者接受；
- 需要输出驱动因子贡献、敏感性、区间和风险等级。

## 5. 技术方案概览

### 5.1 数据层

- V0.4 不可变合成开发数据；
- 网格-日粒度：`grid_id + date`；
- 目标时效：`T+1/3/7/15/30/60/90`；
- 全合法分区均匀抽样；
- 可选滞后/滚动历史特征。

### 5.2 机理层

采用蓝藻日生物量增长/损失过程：

```text
B(t+1) = B(t) × exp(net_growth(t) + noise)
```

其中：

```text
net_growth = gross_growth - respiration - mortality - mixing_loss
```

主要限制因子：

- 温度因子；
- 氮因子；
- 磷因子；
- 光照因子；
- 容量因子；
- 混合/流动损失。

### 5.3 AI 层

- Random Forest；
- XGBoost；
- 简单均值/众数/比例基线。

### 5.4 融合层

- 机理特征融合；
- 机理残差融合；
- 带物理边界的约束融合；
- Stacking 原型。
