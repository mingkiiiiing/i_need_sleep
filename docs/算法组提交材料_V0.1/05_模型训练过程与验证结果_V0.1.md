## 1. 任务与时效覆盖

本矩阵不是只训练了“水华 3 天”和“藻密度 3 天”。实际完成的矩阵为：

```text
9 个监督任务变体 × 7 个预测时效 = 63 个组合
```

| 任务 | 目标 | 已运行时效 |
|---|---|---|
| T1 | 水华发生（二分类） | 1、3、7、15、30、60、90 天 |
| T2-area | 水华面积（回归） | 1、3、7、15、30、60、90 天 |
| T2-coverage | 水华覆盖率（回归） | 1、3、7、15、30、60、90 天 |
| T3 | 蓝藻密度（回归） | 1、3、7、15、30、60、90 天 |
| T4 | 蓝藻生物量（回归） | 1、3、7、15、30、60、90 天 |
| T5 | 叶绿素 a（回归） | 1、3、7、15、30、60、90 天 |
| T6-risk_level | 风险等级（有序分类） | 1、3、7、15、30、60、90 天 |
| T6-probability | 风险概率（回归） | 1、3、7、15、30、60、90 天 |
| T7 | 水华空间范围（空间） | 1、3、7、15、30、60、90 天 |

按题目要求的时间档位归纳：

| 题目时间档 | 矩阵时效 | 运行状态 |
|---|---|---|
| 1-3 天 | T+1、T+3 | 全部完成 |
| 7-15 天 | T+7、T+15 | 全部完成 |
| 30-90 天 | T+30、T+60、T+90 | 全部完成 |

## 2. 运行配置

### 2.1 数据切分

- 窗口 W1：2005-2013 训练，2014-2015 验证；
- 窗口 W2：2005-2015 训练，2016-2017 验证；
- 窗口 W3：2005-2017 训练，2018-2019 验证；
- 窗口 W4：2005-2019 训练，2020-2021 验证；
- 测试：2022-2025 一次性冻结评估。

### 2.2 抽样与隔离

- 每个合法年份、实验湖区都进入候选池；
- 使用固定种子全局均匀抽样；
- 内层校准年为每个窗口训练段最后一年；
- 融合权重在校准年选择后冻结；
- 二元告警阈值在冻结后写入 `selection_manifest.json`；
- 测试集只在 selection manifest 冻结后读取一次。

### 2.3 训练预算

- 每窗口训练样本上限：50,000；
- 每窗口验证样本上限：20,000；
- 测试样本上限：20,000；
- 随机种子：20260907。

### 2.4 候选与超参数

AI 候选统一使用以下默认超参数：

| 候选 | 参数 |
|---|---|
| Random Forest | `n_estimators=120`、`min_samples_leaf=2`、分类使用 `balanced_subsample` |
| XGBoost | `n_estimators=120`、`max_depth=6`、`learning_rate=0.05`、`tree_method=hist` |
| 并行 | 读取 `MODELING_V1_N_JOBS`，默认 12 |
| 回归 | MAE 类任务直接回归；log1p-MAE 类任务在 log 空间训练后反变换 |

机理候选参数：

- 生长率、温度最优范围、氮/磷半饱和常数、光照半饱和、自遮蔽、容量、呼吸/死亡/混合损失等集中在 `synthetic_augmentation/mechanism.py`；
- 参数有 `lower/default/upper` 与 `source_class`；
- 每套参数通过 `parameter_table_sha256()` 记录版本。

### 2.5 数据摘要与运行环境

每个 run 写入 `data_digest.json`：

- `train_rows`
- `validation_rows`
- `train_sha256`
- `validation_sha256`
- `feature_columns`

正式矩阵运行环境：

- Python 3.13
- NumPy、pandas、PyArrow、scikit-learn、XGBoost
- 固定数据 `TAIHU_GRID_SYNTHETIC_AUGMENTATION_V0.4`
- 分片命令与进度文件：`matrix_progress_p0-p3.json`

### 2.6 验证与隔离记录

- 每窗口校准年：训练期最后一年；
- 融合权重：内层校准中位数，测试前冻结；
- 二元阈值：四窗口内层校准中位数，测试前冻结；
- 测试：每个 run 只读取一次；
- 覆盖率检查：年份、月份、湖区、网格、样本摘要均记录。

### 2.7 最终模型保存与交付

每个正式 run 在完成测试后保存：

```text
bundle.joblib
```

最终 bundle 使用 `2005-2021` 完整训练窗口重拟合。完整 63 模型交付包：

- 位置：`算法模型交付包_完整版_V0.2/`
- 模型：63 个
- 命名：`<task>-<variant>-<horizon>d-s20260907.joblib`
- 验证：`test_bundles.py` 返回 `ALL_63_MODELS_OK`
- 服务：`api/server.py`

注意：模型包中阈值同样来自冻结选择清单；运行时预测会按冻结阈值输出二分类结果。

## 4. 结果解读

1. 所有 63 个组合均有测试结果，不存在只覆盖某一时效的情况。
2. T3/T4/T5 等回归任务在 1-3 天误差最低，30-90 天误差随预测距离增加，符合预报任务规律。
3. T7 空间任务中机理单体在多数时效被选中，且测试结果高于纯 AI；说明机理对空间表达有正向价值。
4. 融合候选在部分任务与纯 AI 持平，但没有任何组合在本次修正流程中达到相对纯 AI 10% 提升，因此 10% 门槛按 FAIL 如实记录。
