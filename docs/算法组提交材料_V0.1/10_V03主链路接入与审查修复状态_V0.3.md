## 三、补充训练协议披露（T3/T4）

冻结划分（train≤2021 / val 2022-2023 / test≥2024）下 T3 密度 / T4 生物量的 576 行真实标签（2005-02..2020-11）全部落在 train 期，validation/test 均为 0 行，按原门禁不可训练（insufficient_validation_rows_min5）。补训协议：

- **协议 ID**：`train_internal_time_block_cv_v1`；不改动冻结划分本身，仅在补训副本内把 train 期按月份时间分块（早 70% 月拟合 / 晚 30% 月做族选择与 conformal 残差校准）；
- **残差口径**：早段拟合模型对晚段分块的折外预测；最终模型在全部 train 期重拟合；
- **诚实边界**：冻结测试期无该任务标签，测试指标与经验覆盖率保持空（不伪造）；门禁表中这些 run 记 N.A.（missing_fusion_or_single_family_test_metrics）；
- **选族结果**：T3 密度 = residual（残差融合，cv log1p_mae ≈ 0.148）；T4 生物量 = simple_baseline（cv MAE ≈ 5.71 mg/L）——生物量无可用品模型被选中即如实呈现常数输出；
- **运行层标注**：`results[*].training_protocol` 区分 `frozen_split` 与 `train_internal_time_block_cv_v1`，前端徽标"真实·补训"。

复现命令：

```

# = train-cv（8 run）→ patch availability → gate → manifest → supplemental 段
```
