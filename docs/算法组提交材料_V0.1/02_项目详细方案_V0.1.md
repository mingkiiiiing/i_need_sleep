# 项目详细方案 V0.1

> **📌 现状指引（2026-09-10）**：本文为立项/历史记录，其中模型规模（63）、训练边界与门禁状态为当时时点信息。当前统一指标口径以 [12_命题条款对照与统一指标口径_V0.1.md](12_命题条款对照与统一指标口径_V0.1.md) 为准；真实口径门禁 FAIL、合成环境验证 PASS 见 10/11 号。

## 1. 总体架构

系统按六层设计：

```text
数据接入与质控
数据治理与版本
机理与 AI 建模
评估与隔离
解释与不确定性
业务预警与孪生
```

各层职责如下：

| 层 | 职责 |
|---|---|
| 接入 | 遥感、水质、气象、水文数据标准化 |
| 治理 | 清洗、插补、时空对齐、特征字典、版本/血缘 |
| 机理与 AI | 机理过程、Random Forest、XGBoost、融合候选 |
| 评估 | 全矩阵训练、验证选择、测试冻结 |
| 解释 | SHAP、重要性、敏感性、机理一致性 |
| 预警 | 风险分级、热力图、预警推送、孪生 |

## 2. 数据方案

### 2.1 数据来源与类型

本项目建模开发使用合成 V0.4 数据，字段覆盖：

- 水质：水温、TN、TP、DO、pH、浮游植物生物量；
- 生态目标：蓝藻密度、蓝藻生物量、叶绿素 a；
- 气象：气温、降水、风速风向、辐射、湿度、气压；
- 水文水动力：水位、流速、混合指数；
- 遥感：叶绿素、藻蓝蛋白、密度代理、FAI、NDCI；
- 空间：网格面积、水域面积、中心坐标；
- 标签：水华发生、面积、覆盖率、风险等级、风险概率。

### 2.2 粒度与主键

```text
主键：grid_id + date
```

每行代表一个网格在一个自然日的观测和该日签发的多时效目标。

### 2.3 不可变数据包

`TAIHU_GRID_SYNTHETIC_AUGMENTATION_V0.4`：

- 文件只读；
- 分区按年/湖区；
- 提供 `READY.json`、Manifest、QA 报告；
- 训练不会回写原包；
- 历史/滞后特征以派生方式生成。

### 2.4 时空切分

| 集合 | 时间 |
|---|---|
| 训练 | 2005-2021 内滚动窗口 |
| 验证 | 各窗口后紧跟的年份 |
| 测试 | 2022-2025 |

目标日期跨切分时置空并加 embargo。

## 3. 机理方案

### 3.1 机理方程

采用紧凑蓝藻日生物量增长/损失模型：

```text
gross_growth = μmax
              × temperature_factor
              × nutrient_factor
              × light_factor
              × capacity_factor

net_growth = gross_growth - respiration - mortality - mixing_loss

B_next = B_today × exp(net_growth + process_noise)
```

### 3.2 关键限制因子

温度因子：

```text
temperature_factor
= exp(-((T - T_opt) / width)²)
```

营养盐因子：

```text
nitrogen_factor = TN / (TN + K_N)
phosphorus_factor = TP / (TP + K_P)
nutrient_factor = min(nitrogen_factor, phosphorus_factor)
```

光照因子：

```text
light_factor = I / (I + K_light)
            × exp(-self_shading × biomass)
```

容量因子：

```text
capacity_factor = 1 / (1 + biomass / carrying_capacity)
```

混合与流动：

```text
mixing_loss = mixing_loss_rate × mixing_index
            + flow_loss_rate × flow_speed
```

### 3.3 机理参数管理

- 参数集中保存；
- 每个参数有单位、来源、上下界和默认值；
- 版本通过 SHA-256 固化；
- 参数属于 `literature_informed_range` 或 `mechanism_assumption`，不宣称真实太湖率定结果。

### 3.4 机理 V2

机理 V2 的输入不再只是五类可见因子，而是包括：

- 签发日浮游植物生物量；
- 溶解氧；
- pH；
- 风速；
- 水位；
- 遥感叶绿素/藻蓝蛋白/密度；
- 辐射、混合指数等。

并新增：

- `persistence_projection`：按当前环境持续驱动推进；
- 按 `T+h` 动态推进；
- 校准特征包含状态、过程因子和推进结果。

## 4. AI 方案

### 4.1 候选

- `simple_baseline`：均值/众数/类别比例；
- `random_forest`；
- `xgboost`。

### 4.2 训练约束

- 只使用训练数据拟合预处理器；
- 固定随机种子；
- 时间块隔离；
- 不读取测试集调参；
- 对 log1p 目标在 log 空间训练，再反变换。

## 5. 融合方案

### 5.1 机理特征融合

```text
features = [原始特征, mechanism_prediction]
AI = Random Forest
```

### 5.2 机理残差融合

```text
mechanism_pred → 基线预测
residual = actual - mechanism_pred
AI 学习 residual
final = mechanism_pred + residual_pred
```

### 5.3 约束融合

```text
probability = w × P_mechanism + (1-w) × P_AI
```

权重在滚动窗口内层年度校准段选择，冻结后用于正式重拟合。

### 5.4 Stacking 原型

机理、XGBoost、Random Forest 的预测进入元模型；开发阶段用于观察是否能产生额外增益。

## 6. 滚动训练与隔离

### 6.1 窗口

| 窗口 | 训练 | 验证 |
|---|---|---|
| W1 | 2005-2013 | 2014-2015 |
| W2 | 2005-2015 | 2016-2017 |
| W3 | 2005-2017 | 2018-2019 |
| W4 | 2005-2019 | 2020-2021 |

### 6.2 内层校准

每个窗口训练期最后一年作为内层校准：

```text
inner train = window.train_start ~ year_end - 1
inner cal   = last calendar year
```

校准用于：

- 选择约束融合权重；
- 选择二元告警阈值。

### 6.3 冻结流程

```text
候选训练
→ 窗口验证
→ 选中候选
→ 内层阈值/权重校准
→ 写入 selection manifest
→ 只读一次测试
```

### 6.4 最终模型保存

正式训练完成后，每个 run 会保存最终选中模型：

```text
run_dir/bundle.joblib
```

bundle 包含：

- 最终候选模型；
- 训练集预处理器；
- 特征清单；
- 任务/时效/数据版本；
- 冻结后的告警阈值；
- `claim_boundary`。

完整 63 模型交付包：

## 7. 评估体系

### 7.1 一级指标

| 任务 | 一级指标 |
|---|---|
| T1 | PR-AUC |
| T2 | MAE |
| T3 | log1p-MAE |
| T4 | MAE |
| T5 | MAE |
| T6 risk | Macro-F1 |
| T6 probability | Brier Score |
| T7 | 面积加权 IoU |

### 7.2 业务门槛

- T1：召回率 >= 80%；
- T6：high/severe 召回率检查；
- T2-T5：高强度子集诊断。

### 7.3 诊断指标

- ROC-AUC、F1、精确率；
- RMSE、R²、Spearman；
- 面积误差、质心误差、漏报面积比例。

## 8. 可解释性方案

### 8.1 全局解释

- SHAP；
- permutation importance；
- 变量组聚合。

### 8.2 局部解释

对典型水华、漏报、误报、高强度和长时效样本保存局部 SHAP。

### 8.3 敏感性

对以下驱动做单因素扰动：

- 水温；
- TP；
- TN；
- 溶解氧；
- 光照；
- 风速；
- 水位；
- 混合。

### 8.4 机理一致性

判断敏感性方向是否与生态先验一致，冲突不自动删除，而是标记为 `conflict_review_required`。

## 9. 不确定性方案

### 9.1 分类任务

- 校准概率；
- Brier Score；
- 可靠性曲线；
- ECE。

### 9.2 回归与空间

- 80%/95% 预测区间；
- 覆盖率；
- 平均区间宽度；
- 分位模型或 conformal 方法。

### 9.3 Bootstrap

按日期或完整事件块抽样，不按网格行独立抽样。

## 10. 业务预警与孪生

### 10.1 风险输出

- 风险等级；
- 风险概率；
- 空间范围；
- 区间。

### 10.2 展示

- 湖体底图；
- 风险热力图；
- 历史回放；
- 情景预演；
- 预警推送模拟。

### 10.3 接口约束

每个接口响应必须包含：

- `data_version`
- `model_version`
- `provenance_type`
- `claim_boundary`
- `label_quality`

## 11. 测试方案

- 数据层：分区校验、主键、泄漏、插补；
- 模型层：候选、融合、阈值、隔离；
- 训练层：selection 不读测试、全矩阵完整性；
- 运行层：CLI 复跑、report 汇总。

## 12. 当前限制

1. 使用合成数据，不是真实太湖；
2. 缺少真实天气预报输入；
3. 融合 10% 门槛未达标；
4. 高严重风险样本少；
5. 事件随机性限制高召回下的精确率。
