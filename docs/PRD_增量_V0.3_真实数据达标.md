# PRD 增量 V0.3 —— 真实数据达标与后续攻坚

> 本文档为**增量 PRD**，仅描述 V0.2 → V0.3 的变更部分。V0.2 既有功能（63 个冻结模型、FastAPI 后端、Vue3 前端、7 预测时效 × 9 类输出）不在本文档重述范围内。

---

## 1. 项目信息

- **Language**: 中文
- **Programming Language**: 沿用现有栈（FastAPI + Vue3）；新增数据/训练脚本沿用项目现有 Python 数据栈（pandas / polars + parquet）
- **Project Name**: taihu_bloom_monitor_v0_3
- **原始需求复述**: 太湖蓝藻水华监测预警系统 V0.2 存在 6 项未达标（氨氮缺特征、置信区间非统计口径、遥感反演无校准证据、空间场非连续栅格、10% 提升门禁 FAIL、合规边界），现清洗发布包 TAIHU_CLEAN_FINAL_V1_20260831 已具备真实建模数据（model_dataset.parquet 914 行 × 71 列等），要求全部达标并完成 6 项后续工作。

---

## 2. 产品目标（3 个）

1. **数据真实性达标**：模型管线从 synthetic_development_only 迁移到真实清洗数据（model_dataset.parquet），氨氮、光照、气象驱动等进入特征契约与训练，全部精度表述与真实冻结测试集评估结果绑定。
2. **输出可信度达标**：置信区间改为真实测试集残差校准的统计口径；遥感反演用地面同期配对（226 条 field_samples）校准并给出验证证据；空间场升级为连续卫星反演栅格 + 水华边界。
3. **合规与诚实边界**：10% 提升门禁如实评估（不允许造假）；30-90 天继续保留"情景推演"标注；验收过程可交互核查、可 Git 追溯。

---

## 3. 用户故事

1. 作为**评审专家**，我想在系统中看到氨氮驱动的预测输出且特征契约含真实氨氮字段，以便确认模型使用了完整的关键水质驱动因子。
2. 作为**业务用户**，我想看到带统计校准置信区间（P05-P95）的预测区间，以便判断预测结果的可信范围而非无意义扰动。
3. 作为**遥感数据用户**，我想看到基于 Sentinel-2/MODIS 反演的连续 Chla/水华栅格场与水华边界多边形，并附地面配对校准的验证指标（如 R²/RMSE），以便独立核查反演质量。
4. 作为**团队负责人/验收人**，我想在浏览器中交互核查"达标"结论（10% 门禁比较表、校准曲线、验证指标），以便确认全部达标是如实评估的。
5. 作为**合规审核员**，我想看到 30/60/90 天输出仍明确标注"情景推演"，以便确认产品未越合规边界。

## 6. 验收标准

1. **氨氮达标**：冻结特征契约含 `wq_nh4_n`（及光照/气象字段），契约版本号更新；推理日志可见真实氨氮值参与（插补披露）。全部使用真实数据。
2. **置信区间达标**：测试集上区间经验覆盖率给出实测值（目标 ≈90%，如实报告），口径说明替换为"真实测试集残差校准"，文档与 UI 同步。
3. **遥感校准达标**：留出配对子集上反演验证指标（R²/RMSE）如实给出，校准/验证子集划分记录可追溯；无地面配对的时段明确标注"未校准"。
4. **空间场达标**：输出连续栅格（非 20 站点样点插值）+ 阈值分割水华边界；阈值与分割参数在 manifest 披露。
5. **10% 门禁达标（诚实）**：真实冻结测试集重评，比较数与 PASS/FAIL 如实呈现。**达标 = PASS 比例满足用户定义门禁且口径合规；若未达标则如实标 FAIL 并附差距分析与改进计划，不以任何口径调整粉饰。**
6. **合规达标**：30/60/90 天所有输出（前端 + API）带"情景推演"标注，代码中不可移除。
7. **验收与追溯**：浏览器交互可核查上述 1-6；所有代码/数据产物 Git 提交并打 tag；测试通过（清洗包 303 项测试基线不回退）。

## 7. 待确认问题（主理人已裁定 2026-09-09）

1. **10% 门禁口径**：沿用"预测时效 × 输出类别"逐对比较框架，在真实冻结测试集上重算比较总数（不硬编码 189），PASS 阈值 = 融合相对最强单一 AI 提升 ≥10%；比较表全部落盘可追溯。
2. **配对容差规则**：Sentinel-2 月度产品取地面采样当月记录（月度聚合，天然 ±15 天内）；MODIS 日产品取 ±3 天内最近过境；空间容差取同站点/最近湖内位置，规则写入配对表 manifest。
3. **水华边界阈值**：采用固定阈值（叶绿素 a > 20 μg/L 或等价反演值，参考太湖蓝藻水华业务惯例）并在 manifest 披露；不做分位数自适应以免口径漂移。
4. **重训范围**：重训"真实数据模型族"（RF / XGBoost / 三类融合 × 9 任务 × 7 时效），不覆盖旧 63 个 synthetic bundle（保留为对照与回退）；后端默认服务真实模型族，旧包标注 legacy。
5. **未通过处理**：若重训后 10% 门禁仍 FAIL，如实输出 FAIL + 差距分析 + 改进计划，不阻断交付但不得宣称达标；门禁结论以真实评估为唯一来源。
6. **两组 Sentinel-2 候选取舍**：由工程师对比实验（与地面配对后的校准 R²/RMSE）决定主用组，结论写入 manifest。
