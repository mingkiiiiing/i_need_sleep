## 3. 对比方案

### 3.1 方案一：单一机理模型

| 项目 | 内容 |
| --- | --- |
| 名称 | Logistic + Monod |
| 输入 | 水温、总磷、总氮、光照、风速 |
| 输出 | 机理风险分数 |
| 优点 | 可解释、符合水华形成机理、适合答辩说明 |
| 缺点 | 参数需要校准，对复杂非线性关系表达有限 |
| 当前用途 | 作为机理基线和融合输入 |

### 3.2 方案二：AI模型一

| 项目 | 内容 |
| --- | --- |
| 名称 | Random Forest |
| 输入 | 标准特征表 |
| 输出 | 目标预测值或风险概率 |
| 优点 | 稳健、适合表格数据、可输出特征重要性 |
| 缺点 | 外推能力有限，物理约束弱 |
| 当前用途 | AI基线模型 |

### 3.3 方案三：AI模型二

| 项目 | 内容 |
| --- | --- |
| 名称 | XGBoost 或 GradientBoosting |
| 输入 | 标准特征表 |
| 输出 | 目标预测值或风险概率 |
| 优点 | 能表达复杂非线性和特征交互 |
| 缺点 | 需要调参，对数据质量敏感 |
| 当前用途 | AI对比模型 |

### 3.4 方案四：级联融合

| 项目 | 内容 |
| --- | --- |
| 名称 | Mechanism Cascade Fusion |
| 输入 | 原始特征 + 机理分数 |
| 输出 | 融合预测结果 |
| 思路 | 机理输出作为AI输入特征或加权项 |
| 优点 | 结构简单，便于解释 |
| 缺点 | 权重选择需要验证 |

### 3.5 方案五：残差融合

| 项目 | 内容 |
| --- | --- |
| 名称 | Residual Fusion |
| 输入 | 机理预测、原始特征、真实标签 |
| 输出 | 机理预测 + AI残差修正 |
| 思路 | AI学习机理模型误差 |
| 优点 | 能体现AI对机理不足的补偿 |
| 缺点 | 需要足够真实标签，否则残差学习不稳定 |

## 6. 融合提升计算

融合提升必须基于真实测试集结果计算。

如果指标越大越好，例如 R2、F1、Recall：

```text
提升比例 = (融合模型指标 - 对照模型指标) / 对照模型指标
```

如果指标越小越好，例如 MAE、RMSE：

```text
误差下降比例 = (对照模型误差 - 融合模型误差) / 对照模型误差
```

注意：

- 不能用训练集结果计算提升。
- 不能用样例数据计算比赛效果。
- 如果对照模型指标过低或样本太少，需要说明结果不稳定。

## 9. 结论模板

### 9.1 如果融合模型确实更好

```text
在当前数据版本、时间顺序切分和测试集上，融合模型相较于单一模型在若干指标上取得提升。其中……但该结论仅适用于当前数据范围，后续仍需更多湖区/年份数据验证泛化能力。
```

### 9.2 如果融合模型没有更好

```text
当前测试集中融合模型未稳定优于单一模型。主要可能原因包括样本量不足、负样本不足、机理参数尚未校准或目标标签噪声较高。下一步应优先补充数据与校准机理参数，而不是直接扩大模型复杂度。
```

### 9.3 如果数据不足不能对比

```text
当前数据尚不满足正式融合策略效果对比条件。本报告仅完成方案定义、接口设计和评价模板，不声明模型精度或提升比例。
```
