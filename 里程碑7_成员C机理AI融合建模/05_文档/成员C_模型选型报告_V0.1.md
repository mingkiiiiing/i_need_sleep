# 成员C模型选型报告 V0.1

## 1. 成员C职责定位

成员C负责“机理-AI融合建模”部分，核心目标不是单独做一个黑箱预测模型，而是建立一套能够解释、评估、对比和被后端调用的蓝藻水华预测算法链路。

成员C最终需要交付：

1. 至少一种机理过程模型。
2. 至少两种AI模型。
3. 至少两种机理-AI融合策略。
4. 多时间尺度预测流程。
5. 模型评价指标。
6. 可解释性分析。
7. 不确定性分析。
8. 统一预测函数，供后端调用。
9. 训练过程记录、参数设置与验证结果文档。
10. 机理模型与AI模型融合策略对比分析报告。

## 2. 当前阶段边界

当前数据成员的正式训练数据尚未到位，因此本阶段只完成模型框架和样例链路，不进行真实效果声明。

## 3. 机理模型选型

### 3.1 推荐机理模型：Logistic + Monod 限制函数

选择理由：

- Logistic 增长可以表达藻类种群增长存在上限的特征。
- Monod 限制函数可以表达营养盐限制，例如总磷、总氮不足时，藻类增长受到抑制。
- 模型结构简单、可解释，适合比赛早期实现和答辩说明。
- 可以自然接入水温、光照、风速、营养盐等环境驱动因子。

当前代码对应：

- `02_代码/blue_algae_m7/mechanism.py`
- `mechanism_risk_index(sample)`

当前机理输入字段建议：

| 字段 | 含义 | 作用 |
| --- | --- | --- |
| `water_temperature_C` | 水温 | 控制温度适宜度 |
| `total_phosphorus_mg_L` | 总磷 | 控制磷限制 |
| `total_nitrogen_mg_L` | 总氮 | 控制氮限制 |
| `solar_radiation_MJ_m2_day` | 太阳辐射 | 控制光照条件 |
| `wind_speed_m_s` | 风速 | 表达低风速聚集风险 |

## 4. AI模型选型

### 4.1 AI模型一：Random Forest

选择理由：

- 适合中小规模表格数据。
- 对异常值和非线性关系较稳健。
- 可以输出特征重要性，便于解释。
- 不需要像深度学习一样依赖大量样本。

适合任务：

- 叶绿素a回归。
- 水华面积回归。
- 风险概率或风险等级分类。

数据要求：

- 至少包含连续日期特征和可信标签。
- 需要正样本和可信负样本。
- 训练集和测试集必须按时间顺序切分。

### 4.2 AI模型二：XGBoost 或 GradientBoosting

优先路线：

- 如果本地环境可安装或队伍允许引入依赖，使用 XGBoost。
- 如果无法安装额外依赖，先用 `sklearn` 的 GradientBoosting 作为替代。

选择理由：

- 对表格型环境数据预测能力较强。
- 能处理非线性和特征交互。
- 便于与 Random Forest 形成对比。
- 可用于回归和分类任务。

适合任务：

- 对比单一AI模型效果。
- 作为融合模型中的AI增强部分。
- 后续配合 SHAP 输出解释结果。

## 5. 融合策略选型

### 5.1 融合策略一：级联融合

思路：

先运行机理模型，得到 `mechanism_score`，再把它作为AI模型输入特征之一，或者与AI结果加权融合。

公式示意：

```text
fusion_score = w * mechanism_score + (1 - w) * ai_score
```

优点：

- 实现简单。
- 可解释性强。
- 方便展示“机理约束参与了预测”。

当前代码对应：

- `02_代码/blue_algae_m7/fusion.py`
- `cascade_fusion(...)`

### 5.2 融合策略二：残差融合

思路：

机理模型先给出基础预测，AI模型学习真实值与机理预测之间的残差。

公式示意：

```text
residual = y_true - mechanism_prediction
final_prediction = mechanism_prediction + ai_residual_prediction
```

优点：

- 能体现 AI 对机理模型不足的修正。
- 适合写“融合策略对比分析”。
- 如果真实数据充足，可能比简单加权更有表现空间。

当前代码对应：

- `02_代码/blue_algae_m7/fusion.py`
- `residual_fusion(...)`

## 6. 多时间尺度预测路线

建议统一使用 `forecast_scale` 表达时间尺度：

| 时间尺度 | 代码 | 预测范围 |
| --- | --- | --- |
| 短期预报 | `short_term` | 1-3 天 |
| 中期趋势 | `mid_term` | 7-15 天 |
| 长期风险 | `long_term` | 30-90 天 |

当前框架已经支持这三类尺度的接口，但真实训练需要数据成员提供相应标签构造方式。

## 7. 评价指标路线

如果预测连续值，例如叶绿素a、水华面积、蓝藻生物量，使用：

- MAE
- RMSE
- R2

如果预测分类标签，例如是否水华或风险等级，使用：

- precision
- recall
- F1
- balanced accuracy

融合提升比例必须在真实测试集上计算：

```text
提升比例 = (融合模型指标 - 对照模型指标) / 对照模型指标
```

不同指标方向不同，使用前必须先确认“越大越好”还是“越小越好”。

## 8. 可解释性路线

第一阶段：

- 使用特征重要性排序。
- 使用敏感性曲线展示单因素变化对风险的影响。

第二阶段：

- 如果模型使用 Random Forest 或 XGBoost，补充 SHAP 全局解释和单样本解释。

重点解释因子：

- 水温
- 总磷
- 总氮
- 氨氮
- 风速
- 光照
- 降雨
- 历史滞后风险

## 9. 不确定性路线

第一阶段：

- 使用经验预测区间。

第二阶段：

- 使用 Bootstrap 多次重采样训练。
- 或使用多个模型组成集成，输出预测分布。

最终输出：

- 下界
- 均值
- 上界
- 置信水平
- 风险概率
